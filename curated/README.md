# Curated

A shared space for the team and community to exchange reusable Ante pieces: settings profiles, skills, and whatever proves useful enough to pass around.

## What goes here

| Folder | Contents | How to use |
|---|---|---|
| `profiles/` | Settings profiles (`<name>.settings.json`) | Copy to `~/.ante/` and run `ante --profile <name>` |
| `skills/` | [Agent Skills](https://agentskills.io) folders, each with a `SKILL.md` | Copy into `~/.ante/skills/` for all projects, or `.ante/skills/` for one project |

See the docs for details: [settings profiles](https://docs.antigma.ai/configuration/preference#named-profiles) and [skills](https://docs.antigma.ai/extend/skills).

## Contributing

Open a PR that adds your profile or skill to the matching folder. Include a line or two on what it does and when to reach for it, in the skill's `description` frontmatter or a short README next to the file. New categories are welcome; add a folder and explain it here.

Strip anything personal before submitting: API keys, tokens, absolute paths, private URLs.

Questions and ideas: [Discord](https://discord.gg/CbAsUR434B) or contact@antigma.ai.
