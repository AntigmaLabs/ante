## Prerequisites

Have a provider account or API key handy. To run a model on your own machine, follow the [offline setup](/local/offline).

## Installation

Ante is distributed as a single, self-contained binary with no external dependencies — just download and run.

<Tabs groupId="install">
<TabItem value="script" label="Install script" default>

```sh
curl -fsSL https://ante.run/install.sh | bash
```

By default this installs to `~/.ante/bin` and configures your shell's `PATH`. Open a new terminal to run `ante`, or use `~/.ante/bin/ante` immediately in the current terminal. Run `ante --version` to check the installation; this guide targets **v0.3.9**.

The installer shows the release version, platform, and download size, then confirms the SHA256 check. To install somewhere else, pass `--dir PATH` or set `ANTE_INSTALL_DIR`:

```sh
curl -fsSL https://ante.run/install.sh | bash -s -- --dir ~/.local/bin
curl -fsSL https://ante.run/install.sh | ANTE_INSTALL_DIR=/usr/local/bin bash
```

Run the default installer as your normal user, not with `sudo`. A sudoed home-directory install would leave `~/.ante` root-owned and prevent Ante from saving settings and input history, so the installer refuses that combination.

</TabItem>
<TabItem value="homebrew" label="Homebrew">

```sh
brew install antigmalabs/tap/ante
```

Run `ante --version` to check the installation. Homebrew installs track the `stable` channel, and `ante update` runs `brew upgrade` for you. See [Homebrew installs](/start/update#homebrew-installs).

</TabItem>
</Tabs>

macOS release binaries are Developer ID-signed and notarized, so Gatekeeper accepts them without a manual security bypass.

## Sign in or add a key {#start-with-your-existing-account-or-key}

<span id="interactive-session" />
<span id="use-a-different-provider" />
<span id="log-in-with-antix" />

<Tabs groupId="signin">
<TabItem value="tui" label="TUI" default>

Open a terminal in your project and start Ante:

```bash
cd your-project
ante
```

If you’ve already signed in or exported your API key in this shell, Ante is ready. For a first connection, open `/providers`, select your provider, and press `m` to sign in or paste a key. See [Connect a provider](/usage/providers).

</TabItem>
<TabItem value="cli" label="CLI">

From your project directory, run `ante auth login antix`, finish signing in through the browser, then run `ante --provider antix`.

</TabItem>
</Tabs>

## Run your first task

Try asking Ante to trace a path through the code:

> Where does this project start? Show me the entry point and a test that exercises it.

Press `Enter` and watch which files Ante reads. Then ask “How do I run just that test?” in the same session. To point Ante at a particular file, type `@` and choose it from the list.
