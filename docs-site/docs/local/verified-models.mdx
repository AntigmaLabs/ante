The **Verified models** list in the [offline mode](/local/offline) selector contains GGUF builds tested for compatibility with Ante's agent loop, downloadable from Hugging Face with memory estimates available up front.

Compatibility checks establish that loading, chat templates, and tool calling work. Benchmark results are separate evidence: consult the [eval page](/benchmarks/eval) for scores tied to a specific build and an auditable run.

## Inspect the current list {#current-list}

The built-in list changes with Ante releases. Open **Verified models** in `/offline-mode`, or inspect the models supplied by your installed version:

```bash
ante offline list
ante offline list --json
```

The output includes discovered local GGUF files, download sizes, maximum context, estimated memory fit, and the default-model marker. JSON entries provide a `reference` accepted by `ante offline use` and `--offline-model`, so you do not need to guess a filename.

```bash
ante offline use Qwen3.8-27B --context 32768
ante --offline-model
```

Maximum context is the model's limit, not the load window. With no context set, llama.cpp fits the window to available memory; set one in [model preferences](/local/offline#model-preferences), or with `ANTE_OFFLINE_CONTEXT` when no context is saved. Check the memory-fit estimate before choosing a model.

If an older selection is no longer in the built-in list, you can still use its local GGUF path or add your own verified entry below.

Historical benchmark: Qwen3.6 27B reached **56.2%** across 89 Terminal-Bench 2.1 tasks with 445 trials. That result remains on the [eval page](/benchmarks/eval#terminal-bench-21); it does not imply the model is still in the current built-in list.

## Add your own

Ante merges `~/.ante/verified_models.json` on top of the built-in list at startup. Entries with a `filename` matching a built-in override it; new filenames are appended.

```json
{
  "models": [
    {
      "name": "My Custom Model",
      "repo": "username/repo-name",
      "filename": "model-Q4_K_M.gguf",
      "context_window": 32768,
      "file_size_mb": 5000,
      "kv_cache_bytes_per_token": 131072
    }
  ]
}
```

| Field | Description |
|---|---|
| `name` | Display name in the model selector |
| `repo` | Hugging Face repo the file downloads from |
| `filename` | GGUF filename within the repo (also the merge key) |
| `context_window` | Maximum context the model supports (tokens) |
| `file_size_mb` | Download size in MiB, rounded up; used for memory estimation |
| `kv_cache_bytes_per_token` | KV cache growth per context token, used for memory estimation |

Vision support, tool support, and effort levels are not listed here: Ante reads them from the engine after the model loads.
