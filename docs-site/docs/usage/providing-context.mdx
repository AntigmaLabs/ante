# Providing Context: Files, Folders & the Web

Give the agent exactly the context it needs: reference local files and directories directly in your prompt, or let Ante fetch what it needs from the web.

## Using @ mentions

Type `@` followed by a file or directory path. Ante shows a search dropdown as you type — press Tab to autocomplete, then Enter to confirm.

<img src="/assets/cookbook/files.gif" alt="Adding file context with @ mentions" className="cookbook-demo" />

- **`@path/to/file.rs`** — embeds the full file contents into your message
- **`@path/to/dir/`** — embeds the directory tree listing

Completion covers the full project tree, including files nested more than six directories deep, and honors the same ignore rules as Ante's file tools. Project-relative searches reuse a background-built index for fast fuzzy matching. `~/`, absolute, `../`, and `./` paths also work, so files outside the project remain available.

This ensures the agent sees exactly the code you're asking about, without guessing or searching.

:::tip
If you paste multiple file paths, Ante auto-prefixes them with `@` for convenience. You can reference as many files as you need in a single prompt.
:::

## Images and PDFs

Press `Ctrl+V` or `Ctrl+Shift+V` in the composer to paste a clipboard image; the terminal must pass the shortcut through to Ante. Providers using the OpenAI Responses format preserve user image and PDF attachments in the outgoing request. Image input still depends on the model’s [`support_vision`](/reference/catalog-reference#model-fields) capability: requests to text-only models filter images without changing the saved dialog.

On OpenAI Responses and OpenAI-compatible Chat Completions, images and supported files returned by tools remain associated with the tool call that produced them, including when several tools run together.

If your endpoint limits images per request, set the provider's [`max_request_images`](/reference/catalog-reference#request-image-limits). Ante keeps the newest images and replaces older ones with text markers in the outgoing request; saved history is unchanged. PDFs do not count toward this cap.

## Pulling in web content

Ante can search the web and fetch content from URLs, letting you pull in documentation, look up APIs, or research topics without leaving the terminal. Just ask naturally and Ante will use its web browsing tools to find what you need:

<img src="/assets/cookbook/webbrowse.gif" alt="Ante performing a web search" className="cookbook-demo" />

The agent can:

- **Search the web** for documentation, examples, and answers
- **Fetch a URL** to read its contents directly (e.g., API docs, release notes, blog posts)
- **Summarize** the results and integrate them into the conversation

This is particularly useful when you're working with an unfamiliar library or need to check the latest documentation for a tool or API.

:::note
Fetching a URL (`WebFetch`) is on by default. Full web **search** (`WebSearch`) runs through the provider's native search, so it is available only on a provider that supports it (Anthropic, OpenAI, Gemini, Grok, OpenRouter, or Antix). On those providers it is enabled automatically — no flag needed; on others it is not offered. See the [Tool Reference](/reference/tools-reference#websearch).
:::

:::tip
You can also pipe web content into Ante from the command line: `curl https://example.com/docs | ante -p "summarize this"`.
:::
