Connect Ante to a provider, choose a model, and start a conversation. Use browser sign-in with a supported account or supply your own API key.

## Sign in from the TUI {#authentication}

1. Run `ante` in your project directory.
2. Type `/connect` and choose **Antix**, **Anthropic Subscription**, or **OpenAI Subscription**.
3. Follow the browser sign-in flow, then return to Ante.
4. Open `/providers`, choose the connected provider, and confirm a model.

<img src="/assets/cookbook/connect.gif" alt="Connecting to a provider via /connect" className="cookbook-demo" />

Ante saves your credentials for future sessions. Use `/connect` again when you need to sign in.

## Sign in from the CLI

For Antix, you can complete OAuth sign-in before opening the TUI or running a headless task:

```bash
ante auth login antix
ante --provider antix
```

The first command opens your browser. Finish signing in, then return to the terminal to run the second command.

CLI login currently supports Antix. For Anthropic and OpenAI subscriptions, use `/connect` in the TUI. See [`ante auth`](/reference/cli-reference#ante-auth) for `--no-browser` and `--force` options.

## Use an API key

Export your provider's API key in the shell where you run Ante, then select that provider:

```bash
export ANTHROPIC_API_KEY="your-api-key"
ante --provider anthropic
```

The same flow works with any provider configured to read an environment variable. For example, use `OPENAI_API_KEY` with `--provider openai` or `ANTIX_API_KEY` with `--provider antix-api-key`. Find the exact provider names and variables in the [Catalog Reference](/reference/catalog-reference#built-in-providers).

### Paste a key in the TUI {#paste-an-api-key}

Run `/welcome` and choose **Use API key**. Ante detects the provider from the key prefix, masks and validates the key, then stores it under `~/.ante/auth/` with access limited to your user. An environment key takes precedence over a saved key.

With Anthropic selected on the API-key step, press `Tab` to sign in to the Anthropic Console in your browser and provision a key automatically.

## Choose a model and start working {#selecting-a-provider}

Type `/providers` to choose a connected provider, then confirm a model and effort level. Ante remembers the last model used on each provider. Use `/models` to change models on the current provider during a conversation.

To select a provider and model when launching Ante:

```bash
ante --provider antix --model claude-sonnet-5-5
```

You're ready to [work through a task in the TUI](/usage/tui). See [Models & Effort](/usage/models-and-thinking) for more on choosing and switching models.

## Custom endpoints and local models

For a hosted endpoint or local server that isn't built in, run `/add-provider` in the TUI or follow the [custom catalog recipes](/reference/catalog-reference#custom-catalog). The [Catalog Reference](/reference/catalog-reference) holds provider lists, model metadata, and configuration examples.

To run a model on your own hardware without credentials, follow [Offline Mode](/local/offline).
