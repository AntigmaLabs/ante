Connect Ante to a provider, choose a model, and start a conversation. Use browser sign-in with a supported account or supply your own API key.

## Sign in from the TUI {#authentication}

1. Run `ante` in your project directory.
2. Type `/providers`, select **Antix**, **Anthropic Subscription**, or **OpenAI Subscription**, and press `m` to manage its access (or `Enter` on a provider that isn't set up yet).
3. Choose **Sign in to …** (for example, **Sign in to Antix**), follow the browser flow, then return to Ante.
4. Ante confirms the sign-in inline and shows the account if the provider supplied one. Press `Enter` to continue. If your session was already using another provider, open `/providers` to switch.

<img src="/assets/cookbook/providers.gif" alt="Choosing a provider and its credential in /providers" className="cookbook-demo" />

Ante saves your credentials for future sessions. Open `/providers` and press `m` again when you need to sign in again.

## Sign in from the CLI

Sign in before opening the TUI or running a headless task:

```bash
ante auth login antix        # or anthropic, openai
ante --provider antix
```

The first command opens your browser. Finish signing in, then return to the terminal to run the second command. On a remote machine, add `--no-browser` to print the sign-in URL instead.

To add a second account, give it a label: `ante auth login anthropic/work`. `ante auth list` shows what is stored. See [`ante auth`](/reference/cli-reference#ante-auth) for every command.

To sign in to a service Ante doesn't have built in, or to get tokens from a command such as `gcloud`, see [Custom Sign-ins & Token Commands](/usage/custom-sign-ins).

## Use an API key

Export your provider's API key in the shell where you run Ante, then select that provider:

```bash
export ANTHROPIC_API_KEY="your-api-key"
ante --provider anthropic
```

To store a key instead of exporting it, run `ante auth add <provider>` and paste the key:

```bash
ante auth add anthropic
```

### Paste a key in the TUI {#paste-an-api-key}

Type `/providers`, select the provider, press `m`, and choose **Add or replace API key**. Ante checks the key against the provider, then stores it under `~/.ante/auth/` with access limited to your user. On built-in providers, an environment key takes precedence over a stored one. The same view removes a saved key.

## Choose a model and start working {#selecting-a-provider}

In `/providers`, choose the connected provider and confirm a model. If you saved several accounts, use `←` or `→` on its row to pick the one for this session.

At the prompt, ask “Where does this project handle a missing config file?” and press `Enter`. You can [inspect the code and review a change](/usage/tui) in the same conversation. Use `/models` whenever you want to switch models.

## Custom endpoints and local models

To connect your own endpoint, run `/add-provider`, follow the setup prompts, then choose it in `/providers` after restarting Ante. For manual configuration, see [Custom providers](/reference/catalog-reference#custom-catalog).

To run a model on your own hardware without credentials, follow [Offline Mode](/local/offline).
