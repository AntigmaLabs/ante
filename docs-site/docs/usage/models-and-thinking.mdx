# Models, Providers & Effort

Ante lets you switch between models, providers, and effort levels mid-session — no restart needed. Two dialogs split the job: `/models` refines the model and effort within your current provider, and `/providers` switches providers.

<img src="/assets/cookbook/providers.gif" alt="Choosing a provider and its credential in /providers, then opening its access view" className="cookbook-demo" />

## Selecting a model

Type `/models` in the TUI to open the model selector. It lists the current provider's models (the title shows the scope, e.g. *Switch Model — Anthropic*). Use the arrow keys to pick a model, adjust the effort slider, and press Enter to confirm.

Use `/models <model_id>` to switch directly to a model on the current provider. For example, to use Fable 5.2 on Antix, select Antix in `/providers`. If your endpoint serves the model before it appears in the picker, enter `/models <model_id>` with the ID supplied by Antix.

When you switch models on the same provider, for example from Gemini to Claude on Antix, you can continue the conversation. Ante clears the previous model’s reasoning data and tool-call signatures before sending the next request.

Press `Tab` to hand off to the provider selector when you want to switch providers instead.

## Switching providers

Open `/providers`, highlight a connected provider, and press `Enter` to choose a model. Press `Enter` again to confirm or `Esc` to go back. If you have several accounts, use `←` or `→` on the provider row to choose one first.

You can continue the same conversation after switching. The new provider handles your next message. To connect one for the first time, [sign in or add a key](/usage/providers#authentication).

## Effort

For a harder task, such as diagnosing an intermittent test failure, you can give the model more reasoning effort. Open `/models`, select the model, adjust the slider below the list, and press `Enter`. The slider shows the levels available for that model and is hidden when the model has no adjustable effort.

Ante remembers your choice for each model. To set the effort for a single run:

```bash
ante --effort high -p "Investigate why this test fails intermittently."
```

`min` selects the lowest level the model supports. Some models still reason at that level.

## View reasoning summaries {#readable-reasoning}

Press `Ctrl+O` in chat to open the transcript and inspect the reasoning the model returned. How much you can see depends on the provider. To change the detail requested for summaries, see [Thinking display](/reference/catalog-reference#thinking-display).
