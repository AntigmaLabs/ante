# Eval

**We keep up with the frontier so you don't have to.** New models and harder benchmarks land every few weeks. We run each new model family through the same public eval, and we move to the harder benchmark when the old one saturates. The Ante you install has already been measured against both, with the score and the inference cost on one page.

## Our standard

We hold Ante to the same official standard as the frontier labs' own agents, and every number is built to be checked:

- **The restrictions are official.** Every task keeps the benchmark's own timeout and sandbox resource limits. We never raise them.
- **We benchmark what we ship.** Every eval runs against a pinned, publicly downloadable Ante release, the same binary `ante update` installs (e.g. `0.3.5`). No eval-only branches, no benchmark-specific prompts.
- **The runs are auditable.** Every result links its raw [Harbor](https://github.com/harbor-framework/harbor) run, so anyone can inspect the trials behind the number.
- **Every run starts clean.** When a score drops, we know it reflects a real regression.
- **The results are live.** We publish continuously at [antigma.ai/eval](https://antigma.ai/eval).

> We evaluate the **agent** and how well it channels the model's power — not the model itself.

When a score needs to go up, we improve the harness: the runtime, orchestration, and reliability. A gain that comes from a better system stays. A gain from a prompt tuned to one benchmark is fragile. We also start early and simple: a small, honest eval set drawn from actual failures beats a large contrived one.

## Terminal-Bench 4.1: our primary benchmark

[Terminal-Bench 4.1](https://hub.harborframework.com/datasets/terminal-bench/terminal-bench/5?tab=leaderboard&leaderboard=4-1-0) became our primary benchmark in November 2026. It is where frontier labs' own agents are ranked today: Claude Code, Codex, and Antigravity CLI with their newest models.

It is also the harder test. The top rows of Terminal-Bench 2.1 sit above 85%. On the 66 tasks of 4.1, three of which need a GPU, the best verified row is near 71% (November 2026). That headroom is where harness work shows.

We publish Ante's score across model families instead of one hero number. The current headline: **Ante + Gemini 4 Neon reaches 65.6%** on Ante `0.3.9`, beating Google's native Antigravity CLI on the same model (61.2%) ([raw run](https://hub.harborframework.com/jobs/14a41cbf-298c-4fe4-8559-08b946004797)). With open-weight DeepSeek V4.1 Flash 1017, Ante reaches 40.9% on `0.3.5` for about $38 of inference ([raw run](https://hub.harborframework.com/jobs/c7b8b27d-6759-4e5e-8ca7-3c7c25ff6a43)); the verified Claude Code row for the same model reads 38.5%. Ante is the #1 same-model agent on both.

Current results live in one place, the [dashboard](https://antigma.ai/eval): every model we have run, each next to the verified rows for the same model.

## Why Terminal-Bench

We use [Terminal Bench](https://github.com/harbor-framework/terminal-bench-1) and [Harbor](https://github.com/harbor-framework/harbor) as our primary external benchmark. The team behind Harbor and Terminal Bench are genuine researchers: rigorous, principled, and motivated by getting it right rather than hype.

- **Rigorous.** Unambiguous task specs, deterministic grading where possible, and isolated execution environments.
- **Focused on core capability.** Can the agent accomplish real tasks in a real shell? Reading context, reasoning, acting, verifying: the exact loop we are building Ante around.
- **It keeps moving.** Each release raises the bar as models catch up, and we move with it.
