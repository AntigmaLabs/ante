许多模型提供商 — 包括阿里云/通义千问（Aliyun/Qwen）、MiniMax、Kimi、字节跳动/火山引擎（ByteDance/Ark）、z.ai 等 — 都提供了价格实惠、额度充足的代码计划，这些计划拥有为 AI 编码工具优化的大额每月 API 额度。因为这些计划暴露了标准的 Anthropic 或 OpenAI 兼容端点，所以 Ante 可以开箱即用。

## 阿里代码计划（内置） {#ali-coding-plan-built-in}

Ante 为阿里云代码计划内置了一个 `ali-coding-plan` 提供商。有关配置和可用模型的详细信息，请参阅[目录参考](/reference/catalog-reference#ali-coding-plan)。

## 通用代码计划 {#generic-coding-plans}

以下示例使用了 z.ai DevPack；其他代码计划遵循相同的模式。

### 兼容 Anthropic {#anthropic-compatible}

使用 `anthropic` 提供商，并将 `MODEL_BASE_URL` 指向代码计划的端点。

**示例：z.ai DevPack**

```bash
export ANTHROPIC_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/anthropic"

ante --provider anthropic --model glm-5-turbo -p "refactor the auth module"
```

### 兼容 OpenAI {#openai-compatible}

使用 `openai-compatible` 提供商，并将 `MODEL_BASE_URL` 指向代码计划的端点。

**示例：z.ai DevPack**

```bash
export OPENAI_COMPATIBLE_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/coding/paas/v4"

ante --provider openai-compatible --model glm-5-turbo -p "add unit tests for the cache layer"
```
