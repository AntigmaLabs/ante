许多模型提供商（包括 阿里云/Qwen、MiniMax、Kimi、字节跳动/豆包、z.ai 等）都提供价格实惠、额度充足的编程套餐，这些套餐拥有针对 AI 编程工具优化的大容量月度 API 配额。因为这些套餐暴露出标准的 Anthropic 或 OpenAI 兼容的端点，Ante 可以开箱即用地支持它们。

## 阿里云编程套餐（内置）

Ante 拥有一个针对阿里云编程套餐的内置 `ali-coding-plan` 提供商。请参阅 [目录参考](/reference/catalog-reference#ali-coding-plan) 了解配置和可用模型。

## 通用编程套餐

以下示例使用 z.ai DevPack；其他编程套餐遵循相同的模式。

### 兼容 Anthropic

使用 `anthropic` 提供商，并将 `MODEL_BASE_URL` 指向该套餐的端点。

**示例：z.ai DevPack**

```bash
export ANTHROPIC_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/anthropic"

ante --provider anthropic --model glm-5-turbo -p "重构 auth 模块"
```

### 兼容 OpenAI

使用 `openai-compatible` 提供商，并将 `MODEL_BASE_URL` 指向该套餐的端点。

**示例：z.ai DevPack**

```bash
export OPENAI_COMPATIBLE_API_KEY="your_z_ai_key"
export MODEL_BASE_URL="https://api.z.ai/api/coding/paas/v4"

ante --provider openai-compatible --model glm-5-turbo -p "为缓存层添加单元测试"
```
