# 原生智能体集成

Antix 是 **Ante CLI** 的集中式控制平面，将企业级治理引入本地编程智能体。

## 将 Ante 连接到 Antix

开发人员根据您的 Antix 服务器验证其本地 Ante 实例：

1. 启动 `ante` CLI。
2. 输入 `/connect`。
3. 从菜单中选择 **Antix**。

这会安全地向 Antix 控制平面验证您的本地智能体，授予其一个临时访问令牌，该令牌会根据需要自动刷新。

## 优势

- **成本归因** — 工程师从 Ante CLI 运行的每个提示词都会在计费分类账和分析时间轴中归因到其用户 ID。
- **模型治理** — 通过组织级别的模型默认设置，限制本地智能体可以使用的模型。
- **部分离职处理（Partial offboarding）** — 在门户网站中移除成员会归档其个人端点，在几秒钟内切断通过这些 URL 的流量（参见 [组织](/antix/concepts/organizations)）。这**不会**撤销该成员的虚拟密钥或活动的 OAuth 会话——如需完全切断，请撤销其密钥或删除其账户。
