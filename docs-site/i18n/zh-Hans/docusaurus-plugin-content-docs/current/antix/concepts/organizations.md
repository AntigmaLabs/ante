# 组织和基于角色的访问控制 (RBAC)

Antix 在设计上支持多租户。**组织（Organizations）** 是最高级别的计费和访问边界——用户、虚拟密钥、支出和分析均限定于组织内。

## 角色模型

组织有两类角色：

- **管理员（Admin）** — 管理成员、邀请、虚拟密钥、预算和组织设置。
- **成员（Member）** — 使用提供的密钥消费 API。无法管理成员、查看待处理的邀请或更改组织设置。

角色执行机制通过在修改状态之前检查调用者的角色，确保对操作进行安全的访问控制。


## 管理成员

组织管理员可以直接从 Antix 门户网站仪表板（位于 [https://portal.antigma.ai](https://portal.antigma.ai)）邀请成员、分配角色并移除成员。

**撤销权限**
从门户网站中移除成员会将他们的个人端点归档，并移除其组织成员身份——这几乎是实时的，因为解析器缓存会被同步失效，而不是等待缓存的生存时间（TTL）过期。

:::note
移除成员**不会**撤销该成员的虚拟密钥或活动的 OAuth 会话。前成员的密钥仍然可以用于组织共享的端点，直到它被单独撤销。为了完全切断访问，请显式撤销该成员的密钥或删除其账户。
:::
