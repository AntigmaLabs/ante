Ante 可以连接到 [模型上下文协议（Model Context Protocol）](https://modelcontextprotocol.io) 服务器，将其工具暴露给代理。每个配置的服务器都会作为一个子进程启动，其工具就像任何内置工具一样可被调用。

## 配置

MCP 服务器在 `~/.ante/settings.json` 的 `mcp_servers` 映射中进行声明。键是本地服务器名称；值描述了如何启动它。

```json
{
  "mcp_servers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "ghp_..." }
    }
  }
}
```

| 字段 | 是否必需 | 描述 |
|---|---|---|
| `command` | 是 | 用于生成服务器进程的可执行文件 |
| `args` | 否 | 传递给命令的参数 |
| `env` | 否 | 在服务器进程上设置的环境变量 |
| `enabled_tools` | 否 | 要暴露的原始工具名称的允许列表。如果为空或不存在，则暴露该服务器的所有工具 |

仅支持 **stdio** 传输方式 —— Ante 生成命令，通过其 stdin/stdout 进行 MCP 通信，并将 stderr 转发到日志。

## 工具命名

服务器提供的每个工具都会以 `mcp__<server>__<tool>` 的形式暴露给代理。这两部分中的非字母数字字符都会被替换为 `_`，因此键为 `my-server` 的服务器中名为 `do.thing` 的工具将变为 `mcp__my_server__do_thing`。

MCP 工具遵循与内置工具相同的 `--include-tools` / `--exclude-tools` 过滤规则 —— 如果使用了严格的包含列表且未列出它们，它们将被移除。为了在不受会话过滤器影响的情况下精确控制每个服务器所暴露的工具，请使用 `enabled_tools`：

```json
{
  "mcp_servers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"],
      "enabled_tools": ["read_text_file", "write_file"]
    }
  }
}
```

## 生命周期

MCP 预热在后台**延迟**运行，以便守护进程保持响应。当会话开始时：

1. `SessionStart` 和初始的 `ExtensionRefreshed` 事件会立即触发 —— 输入可以立刻使用。
2. 后台任务并行连接到所有配置的服务器（每次握手超时时间为 30 秒）。
3. 随着每个服务器的工具被发现，它们会被添加到实时工具注册表中；上线的工具将在**下一轮（turn）**变得可调用（正在进行中的轮次将保持冻结快照）。
4. 一旦预热完成，将触发第二次 `ExtensionRefreshed` 事件，以便 `/mcp` 面板能够填充每个服务器已发现的工具列表。

进度通过分组通知呈现给用户（一个 `InfoBlockStart` 加上后续的 `InfoBlockAppend` 事件 —— 参见[协议参考](/reference/protocol-reference#infoblockstart)）：

```
* Warming up 4 MCP servers in the background — tools will become available as they connect.
  └ MCP ready: 4/4 servers connected, 60 tools registered.
```

未能连接（或未能列出其工具）的服务器会被记录在日志中并被跳过，然后在预热块下的子行中进行报告。服务器进程将在整个会话期间保持运行状态，并在守护进程退出时终止。

## `/mcp` 命令

在 TUI 中，运行 `/mcp` 来检查配置的服务器。选择器会列出每个服务器及其连接状态、暴露的工具数量和命令。在服务器上按 `Enter` 键可查看每个工具的详细信息（描述和参数），或按 `d` 键将该服务器从 `settings.json` 中移除。

目前选择器尚未包含在 TUI 内添加新服务器的流程，因此需要直接编辑 `~/.ante/settings.json` 来添加新服务器。

## 批准

默认情况下，MCP 工具不需要批准。如果需要，可使用 `--exclude-tools` 或权限规则来对特定工具进行限制。
