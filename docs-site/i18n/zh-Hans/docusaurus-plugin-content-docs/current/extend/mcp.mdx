Ante 可以连接到 [模型上下文协议 (Model Context Protocol, MCP)](https://modelcontextprotocol.io) 服务器，将它们的工具暴露给智能体。每个配置的服务器都会作为一个子进程启动，其工具会像任何内置工具一样可以被调用。

<img src="/assets/mcp-demo.gif" alt="在 Ante TUI 中的 MCP 服务器检查和工具调用" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

## 配置 {#configuration}

MCP 服务器在 `~/.ante/settings.json` 的 `mcp_servers` 映射下声明。键是本地服务器名称；值描述了如何启动它。

```json
{
  "mcp_servers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "ghp_..." }
    }
  }
}
```

| 字段 | 是否必需 | 描述 |
|---|---|---|
| `command` | 是 | 生成服务器进程的可执行文件 |
| `args` | 否 | 传递给命令的参数 |
| `env` | 否 | 在服务器进程上设置的环境变量 |
| `enabled_tools` | 否 | 允许暴露的原始工具名称的许可列表。当该项为空或不存在时，暴露服务器中的所有工具 |

仅支持 **stdio** 传输方式 — Ante 派生出该命令进程，通过其 stdin/stdout 进行 MCP 通信，并将 stderr 转发到日志中。

## 工具命名 {#tool-naming}

服务器提供的每个工具都会作为 `mcp__<server>__<tool>` 暴露给智能体。这两部分中的非字母数字字符都会被替换为 `_`，因此一个键为 `my-server` 且其中有名为 `do.thing` 工具的服务器，会变成 `mcp__my_server__do_thing`。

MCP 工具遵循与内置工具相同的 `--include-tools` / `--exclude-tools` 过滤规则 — 如果一个严格的包含列表没有命名它们，它们将被剥离。若要控制每个服务器暴露的内容而不受会话过滤器的影响，请使用 `enabled_tools`：

```json
{
  "mcp_servers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"],
      "enabled_tools": ["read_text_file", "write_file"]
    }
  }
}
```

## 生命周期 {#lifecycle}

MCP 的预热在后台**延迟**运行，以保持守护进程的响应速度。当会话开始时：

1. `SessionStart` 和初始的 `ExtensionRefreshed` 立即触发 — 输入功能马上可用。
2. 一个后台任务并行连接到所有配置的服务器（每个服务器有 30 秒的握手超时限制）。
3. 随着每个服务器的工具被发现，它们会被添加到实时工具注册表中；上线的工具在**下一个回合**就变得可被调用（正在进行中的回合保持冻结的工具快照）。
4. 预热完成后，会发出第二次 `ExtensionRefreshed`，以便使用每个服务器发现的工具列表填充 `/mcp` 面板。

预热进度会通过一个分组通知展示给用户（包含一个 `InfoBlockStart` 以及后续的 `InfoBlockAppend` 事件 — 参见[协议参考](/reference/protocol-reference#infoblockstart)）：

```
* Warming up 4 MCP servers in the background — tools will become available as they connect.
  └ MCP ready: 4/4 servers connected, 60 tools registered.
```

未能连接（或未能列出其工具）的服务器会被记录在日志中，被跳过，并作为预热块下的子行报告。服务器进程将在会话期间保持存活，并在守护进程退出时终止。

## `/mcp` 命令 {#the-mcp-command}

在 TUI 中，运行 `/mcp` 以检查已配置的服务器。选择器列出了每个服务器及其连接状态、暴露的工具数量和命令。在服务器上按 `Enter` 键可查看每个工具的详细信息（描述和参数），或按 `d` 键从 `settings.json` 中删除该服务器。

添加新服务器可以直接通过编辑 `~/.ante/settings.json` 来完成；目前选择器不包含 TUI 内的添加流程。

## 审批 {#approval}

MCP 工具默认不需要审批。如果需要，请使用 `--exclude-tools` 或权限规则来对特定工具进行把关。
