技能（Skills）是包含指令、脚本和资源的文件夹，用于扩展 Ante 的功能。它们遵循开放的 [Agent Skills](https://agentskills.io) 格式，使其在兼容的代理产品之间具有可移植性。

## 创建技能

技能是一个包含 `SKILL.md` 文件的目录：

```
commit/
└── SKILL.md
```

`SKILL.md` 使用 YAML 前文（frontmatter），后跟 Markdown 指令：

```markdown
---
name: commit
description: Create a git commit with a descriptive message following conventional commit format.
---

Look at the current git diff and create a commit with a clear,
descriptive message that follows conventional commit format.
Use `git add` to stage relevant files first.
```

### 示例：带有工具和参考资料的 review 技能

```
review/
├── SKILL.md
└── references/
    └── checklist.md
```

```markdown
---
name: review
description: Review code changes for bugs, security issues, and style.
argument-hint: <path>
---

Review the code at $ARGUMENTS for bugs, security vulnerabilities, style issues, and missing error handling.

See [checklist](references/checklist.md) for the full review checklist.
```

前文解析对常见的标量错误较为宽容：如果未加引号的值包含 `: `、以诸如 `[` 或 `{` 等流控制字符开头，或包含内联注释，当它们可以被明确解释时，会被修复。格式错误的嵌套 YAML 仍然会失败，以确保损坏的元数据不会被静默加载。

## 技能目录

| 目录 | 作用域 |
|---|---|
| `~/.agents/skills/` | 用户级别（兼容性 —— 在 `~/.ante/skills/` 之前加载） |
| `~/.ante/skills/` | 用户级别（所有项目均可使用） |
| `.agents/skills/` | 项目级别 |
| `.ante/skills/` | 项目级别 |
| `.claude/skills/` | 项目级别（兼容 Claude Code） |

## SKILL.md 前文

| 字段 | 是否必需 | 默认值 | 描述 |
|---|---|---|---|
| `name` | 否 | 目录名称 | 技能的标识符 |
| `description` | 否 | 第一段 | 此技能的作用以及何时使用它 |
| `argument-hint` | 否 | — | 预期参数的提示文本（例如 `<path>`） |
| `user-invocable` | 否 | `true` | 该技能是否可以通过斜杠命令调用 |
| `disable-model-invocation` | 否 | `false` | 防止模型自动调用此技能 |
| `metadata` | 否 | — | 任意键值对 |

来自其他代理产品的未识别字段（例如 `allowed-tools`）会被宽容对待但忽略，因此现有技能无需修改即可加载。

## 可选目录

```
my-skill/
├── SKILL.md           # 必需 —— 指令
├── scripts/           # 代理可运行的可执行代码
├── references/        # 按需加载的附加文档
└── assets/            # 模板、模式、数据文件
```

## 技能发现方式

技能按优先级顺序被发现（按技能名称，后面的会覆盖前面的）：

1. 系统级别（内置技能）
2. `~/.agents/skills/`（用户级别，兼容性）
3. `~/.ante/skills/`（用户级别）
4. `.claude/skills/`（项目级别，兼容 Claude Code）
5. `.agents/skills/`（项目级别）
6. `.ante/skills/`（项目级别）

## 使用技能

```
/commit
/review src/core/session.rs
```

您在技能名称后输入的任何内容都会作为参数传递给技能。它们如何出现在指令中，取决于技能使用的占位符：

| 占位符 | 替换为 |
|---|---|
| `$ARGUMENTS` | 完整的参数字符串，逐字保留 |
| `${1}`, `${2}`, … | 第一个、第二个……以空格分隔的参数（带引号的值将作为一个整体） |
| `${1:default}` | 位置参数，如果缺失则使用 `default` |

如果技能的指令中未包含占位符，参数将附加在 `<arguments>` 块中，以确保代理仍然能够看到它们。
