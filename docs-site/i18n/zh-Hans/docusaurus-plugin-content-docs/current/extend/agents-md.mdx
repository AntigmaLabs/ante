# AGENTS.md 指引文件

`AGENTS.md` 文件为 Ante 提供了独立于自动记忆之外的持久化行为规则指引。适用于团队为智能体定制在当前项目中工作时必须遵守的稳定规则。

## 文件路径与作用域

当会话中提交首条用户消息时，Ante 会自动读取以下两处指引文件：

| 位置 | 作用域 |
|---|---|
| `~/.ante/AGENTS.md` | 适用于所有项目的用户级全局指引 |
| `<project>/AGENTS.md` | 纳入代码版本控制的项目专属指引 |

全局路径遵循 `ANTE_HOME` 环境变量配置。

### 兼容 CLAUDE.md

为了保持与 Claude Code 的无缝兼容，在不存在 `AGENTS.md` 时会自动回退读取 `CLAUDE.md`：

- **项目级**：Ante 从当前工作目录向上递归查找；在每个父级目录中优先检查 `AGENTS.md`，其次检查 `CLAUDE.md`。首次找到的目录胜出；若同一目录下两者并存，仅读取 `AGENTS.md`。
- **全局级**：优先读取 `~/.ante/AGENTS.md`，仅当该文件不存在时才回退读取 `~/.claude/CLAUDE.md`。

## 指引注入机制

若全局和项目指引同时存在，Ante 会将其合并为一个提示词提醒块（全局规则在前，项目规则在后）注入系统提示词。空文件会被自动忽略。

项目指引适用于仓库专属的构建命令、代码规范与架构设计约束；全局指引更适合配置跨项目的个人偏好（如回复风格、语言偏好等）。

## 配置示例

```markdown title="~/.ante/AGENTS.md"
# 全局偏好

- 保持回复简洁精炼。
- 优先提供可直接执行的操作与结论，减少不必要的背景铺垫。
```

```markdown title="AGENTS.md"
# 项目规则

- 修改 Rust 代码前先运行 `cargo test --workspace` 确保基线测试通过。
- 保证公共协议变动的向后兼容性。
- 新增或调整 CLI 参数与配置项时同步更新对应文档。
```

## AGENTS.md 与 MEMORY.md 的区别

- `AGENTS.md` 是**人工编写的规则规范**。Ante 将其视为必须严格遵守的强制性行为准则。
- `MEMORY.md` 是**智能体自动生成的记忆**。Ante 用其记录跨会话学习到的经验与上下文。
