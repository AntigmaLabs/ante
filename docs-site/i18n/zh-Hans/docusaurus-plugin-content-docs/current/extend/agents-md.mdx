---
title: "AGENTS.md"
description: "加载到每个 Ante 会话中的项目指令和全局指令"
---

`AGENTS.md` 文件为 Ante 提供了独立于自动记忆的持久指令。使用它们来设定智能体在项目中工作时每次都应遵循的稳定规则。

## 位置 {#locations}

当在会话中提交第一条用户消息时，Ante 会读取两个指令文件：

| 位置 | 作用域 |
|---|---|
| `~/.ante/AGENTS.md` | 适用于所有项目的全局指令 |
| `<project>/AGENTS.md` | 签入代码库的项目指令 |

全局路径遵循 `ANTE_HOME` 的设置，因此如果您设置了 `ANTE_HOME=/path/to/ante-home`，全局文件则为 `/path/to/ante-home/AGENTS.md`。

## Ante 如何应用指令 {#how-ante-applies-instructions}

如果这两个文件都存在，Ante 会将它们包含在一个提醒块中，全局文件在先，项目文件在后。空文件会被忽略。如果全局路径和项目路径解析为同一个文件，Ante 只会包含它一次。

项目指令旨在用于特定代码库的规则，例如构建命令、编码约定和架构约束。全局指令更适合用于随处适用的个人偏好，例如响应格式或语言风格。

## 示例 {#example}

```markdown title="~/.ante/AGENTS.md"
# 全局偏好设置

- 保持回答简明扼要。
- 优先提供可操作的解释，而不是背景信息。
```

```markdown title="AGENTS.md"
# 项目规则

- 在更改 Rust 代码之前，运行 `cargo test --workspace`。
- 保持公共协议的更改向后兼容。
- 当 CLI 标志或配置文件发生更改时，更新文档。
```

## AGENTS.md 与 MEMORY.md 对比 {#agentsmd-vs-memorymd}

`AGENTS.md` 是由人类编写的指导。Ante 将其作为关于如何表现的指令来读取。

`MEMORY.md` 是生成的项目记忆。Ante 使用它在不同会话之间携带学习到的上下文。

使用 `AGENTS.md` 来设定您想要强制执行的规则。使用记忆来记录智能体在了解代码库时可能会发生变化的观察结果。
