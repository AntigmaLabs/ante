Ante 拥有一个持久化记忆系统，允许代理在多次对话中积累知识。见解、模式和经验教训被存储在记忆文件中，并自动加载到后续会话的系统提示词（system prompt）中。

## 工作原理

每个项目在 `~/.ante/projects/<project-id>/memory/` 都有一个记忆目录，其中 `<project-id>` 是项目绝对路径的经过清理的格式。核心文件是 `MEMORY.md` —— 在每次对话开始时，它的内容会被注入到系统提示词中。

自动记忆在交互式 TUI 中默认启用，在无头（headless）的 `-p` 运行中默认禁用。使用 `--enable-auto-memory` 可以在无头运行中开启记忆功能，或者使用 `--disable-auto-memory` 在 TUI 会话中关闭它。

### 自动行为

随着代理在您的项目中工作，它会：

1. **查阅**现有的记忆文件，以借鉴以往经验
2. **记录**在遇到常见错误或有用模式时产生的新见解
3. **更新**或删除被证明是错误或过时的记忆

### MEMORY.md

主记忆文件。它被注入到系统提示词中，上限为 200 行或 25 KB，以先到者为准（溢出时会附加截断提示）。请保持简洁 —— 详细信息可链接到独立的主题文件。

```markdown
# 项目模式

- 对所有可能失败的函数使用 `anyhow::Result`
- 测试放置在与代码同目录的 `#[cfg(test)]` 模块中
- 常见问题请参阅 [debugging.md](debugging.md)

# 已知问题

- 认证模块需要重构（在 #123 中跟踪）
```

### 主题文件

对于详细的笔记，请创建单独的文件并在 `MEMORY.md` 中引用它们：

```
memory/
├── MEMORY.md           # 主文件（自动加载，最多 200 行）
├── debugging.md        # 详细的调试笔记
├── patterns.md         # 代码模式与约定
└── architecture.md     # 架构决策
```

## 记忆类型

当开启自动记忆时，代理会被教导保存**类型化**的记忆 —— 每个主题文件都带有 `name`、`description` 和 `type` 的前文，以便未来的会话决定哪些内容是相关的。共有四种类型：

| 类型 | 记录内容 |
|---|---|
| `user` | 用户的角色、专业知识、目标和偏好 —— 以便为他们量身定制解释和默认设置。 |
| `feedback` | 关于如何在该项目中工作的指南，从纠正和确认中提取。首先陈述规则，然后是**原因（Why）**和**如何应用（How to apply）**。 |
| `project` | 无法从代码或 git 推导出的正在进行的工作、决策或约束。具有相同的**原因** / **如何应用**结构；相对日期被存储为绝对日期。 |
| `reference` | 指向外部系统中当前真相所在位置的指针（例如 Linear 项目、Grafana 面板、Slack 频道）。 |

类型化的主题文件如下所示：

```markdown
---
name: bundle-refactors
description: Prefer one bundled PR for refactors in this area
type: feedback
---

在这里进行多文件重构时，倾向于合并为一个 PR，而不是拆分。

**原因：**用户确认了这一点 —— 这是经验证的调用，而不是纠正。
**如何应用：**涉及此区域的多文件重构。
```

代理有意**不**保存机密信息、进行中的任务状态，或任何已经可以从仓库中重新读取的内容（代码结构、文件路径、约定 —— 这些属于 `AGENTS.md`）。提取的记忆被视为反映过去某个时刻的背景上下文，因此代理在对其采取行动之前，会重新验证记忆中提到的任何文件、标志或函数。

## 指南

记忆系统遵循以下原则：

- **简洁** —— `MEMORY.md` 在 200 行后会被截断，所以请保持聚焦
- **语义化** —— 按主题组织，而不是按时间顺序
- **准确** —— 更新或删除过时的信息
- **可操作** —— 记录有效和无效的方法以及原因

## 记忆是针对每个项目的

记忆的作用域限定于每个项目目录。不同的项目拥有独立的记忆目录。这意味着代理在您的 React 前端项目积累的知识不会干扰其在 Rust 后端项目的知识。

## 手动编辑

您可以直接编辑记忆文件 —— 它们是纯 Markdown。代理也可以在会话期间使用 `Write` 和 `Edit` 工具来更新它们。
