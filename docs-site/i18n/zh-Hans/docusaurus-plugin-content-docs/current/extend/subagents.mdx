# Sub-Agents 子智能体

Sub-Agents（子智能体）是主智能体在处理复杂、多步骤任务时动态派生出的专门智能体。每个子智能体在专属的上下文、提示词、工具集合以及可选的独立模型配置下运行。

## 内置子智能体

Ante 内置了两种开箱即用的子智能体：

### general（通用研究子智能体）

通用研究型智能体，擅长深入调研复杂问题、多维度搜索代码并执行多阶段子任务。当主智能体需要进行无法在几次简单尝试内完成的探索时会委派给它。

### explorer（代码探索子智能体）

针对代码库结构探索高度优化的高速智能体。能快速按模式定位文件、按关键字搜索代码并梳理代码库的整体架构。

## 创建自定义子智能体

在 `~/.ante/agents/`（用户全局）或项目级目录（如 `.ante/agents/`）中创建包含 Frontmatter 的 Markdown 文件：

```markdown
---
name: security-reviewer
description: 针对安全漏洞和 OWASP Top 10 问题审查代码
tools:
  - Read
  - Grep
  - Glob
---

你是一名专注于安全合规的代码审查专家。请对给出的代码重点分析以下方面：

- 注入类漏洞 (SQL, Command, XSS)
- 身份认证与授权机制缺陷
- 敏感数据泄露风险
- 安全配置错误
- 已知漏洞依赖

输出明确的严重级别评估与具体的修复建议。
```

### Frontmatter 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 子智能体的唯一标识名称 |
| `description` | 是 | 职责描述（主智能体根据此描述决定何时委派） |
| `model` | 否 | 单独覆盖该子智能体使用的大语言模型 |
| `tools` | 否 | 严格限制该子智能体允许调用的工具列表 |

## 协同工作机制

当主智能体遇到匹配子智能体描述的任务时，会通过内置的 `Agent` 工具拉起子智能体：

1. 主智能体评估当前可用的子智能体及其职责范围；
2. 通过 `Agent` 工具携带详细的任务上下文发起委派；
3. 子智能体在独立的上下文中闭环执行；
4. 执行结束后将最终结论和成果返回给主智能体，主智能体将其融入主对话流。

子智能体会自动继承父会话中启用的 [Skills 技能](/extend/skills)。委派深度限制为一层：子智能体本身不具备 `Agent` 工具，无法继续派生下级智能体。
