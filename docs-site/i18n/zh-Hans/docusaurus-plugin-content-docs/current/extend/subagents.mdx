---
title: "Sub-Agents"
description: "将复杂的任务委派给专门的子代理"
---

子代理（Sub-agents）是专用的代理，主代理可以生成它们来处理复杂的多步任务。每个子代理都使用自己的提示词、工具集运行，并可选择覆盖所用的模型。

## 内置子代理

Ante 附带三个内置子代理：

### general

一个通用代理，用于研究复杂问题、搜索代码以及执行多步任务。当主代理需要执行一次搜索，且不确定能否在几次尝试内完成时，它会将任务委派给此代理。

### explorer

一个专门用于代码库探索的快速代理。它可以根据模式快速查找文件，搜索代码中的关键字，并回答有关代码库结构的问题。

### ante-guide

一个用于解答有关 Ante 本身问题的助手 —— 涉及功能、配置、协议、技能和子代理。主代理将用户关于 Ante 自身功能的问题路由到此处。

## 创建自定义子代理

在 `~/.ante/agents/`（用户级别）或以下任意项目级别位置中创建一个带有 YAML 前文的 Markdown 文件：

```markdown
---
name: security-reviewer
description: Reviews code for security vulnerabilities and OWASP top 10 issues
tools:
  - Read
  - Grep
  - Glob
---

您是一名专注于安全的代码审查员。分析提供的代码，查找：

- 注入漏洞（SQL、命令、XSS）
- 身份验证和授权缺陷
- 敏感数据泄露
- 安全配置错误
- 已知有漏洞的依赖项

提供带有严重性评级和修复步骤的调查结果。
```

### 前文字段

| 字段 | 是否必需 | 描述 |
|---|---|---|
| `name` | 是 | 代理的唯一标识符 |
| `description` | 是 | 该代理的作用（展示给主代理用于委派决策） |
| `model` | 否 | 覆盖此代理的 LLM 模型 |
| `tools` | 否 | 限制此代理可以使用的工具 |

## 子代理如何工作

当主代理遇到符合子代理描述的任务时，它会使用 `Agent` 工具生成该子代理：

1. 主代理评估可用的子代理及其描述
2. 它通过带有详细提示词的 `Agent` 工具委派任务
3. 子代理在自己的上下文中独立运行
4. 结果返回给主代理，主代理将其整合到对话中

```
┌────────────┐     Agent     ┌──────────────┐
│ Main Agent │ ────────────▶ │  Sub-Agent   │
│            │ ◀──────────── │  (Explorer)  │
│            │    Result     └──────────────┘
│            │
│            │     Agent     ┌──────────────┐
│            │ ────────────▶ │  Sub-Agent   │
│            │ ◀──────────── │  (General)   │
└────────────┘    Result     └──────────────┘
```

## 发现机制

子代理按优先级顺序被发现（按名称，后面的会覆盖前面的）：

1. 内置代理（`general`、`explorer`、`ante-guide`）
2. `~/.ante/agents/`（用户级别）
3. `.agents/agents/`（项目级别）
4. `.ante/agents/`（项目级别）
5. `.claude/agents/`（项目级别，兼容 Claude Code）

用户和项目代理与内置代理一起加载。所有可用的代理均在会话初始化时注册，并通过 `ExtensionRefreshed` 协议事件进行刷新。
