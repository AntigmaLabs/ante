# 资源占用

只有当单个代理的运行成本足够低以支持大规模倍增时，大规模并行化才有意义。为了衡量这一点，我们在施加相同约束的 Docker 容器中，让 Ante、Claude Code 和 Opencode 并行执行相同的 20 个任务，并记录了整个运行过程中的 CPU、内存和磁盘使用情况。

主要结论：在相同的工作负载下，与 Claude Code 相比，Ante 的**峰值内存使用量减少了约 7 倍**，**平均 CPU 使用量减少了约 9 倍**，**磁盘 I/O 减少了约 5 倍**。
