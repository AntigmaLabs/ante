# 基准测试 {#benchmarks}

## 我们对发布版本进行基准测试 {#we-benchmark-what-we-ship}

我们的基准测试旨在便于验证：

- **我们对发布版本进行基准测试。** 每次评估都针对指定的、可公开下载的 Ante 发布版本运行，即与 `ante update` 安装的相同二进制文件（例如 `0.preview.43`）。没有专用于评估的分支，也没有专门针对基准测试的提示词。
- **运行过程是可审计的。** 每个结果都链接到其原始的 [Harbor](https://github.com/laude-institute/harbor) 运行记录，因此任何人都可以检查数字背后的实验情况。
- **限制条件是官方的。** 所有实验都使用与官方 Terminal-Bench 排行榜相同的参数：89 个任务，每个任务 5 次实验，严格的超时和硬件限制。
- **结果是实时的。** 我们在 [antigma.ai/eval](https://antigma.ai/eval) 持续发布结果。

## Terminal-Bench 2.1: 一个控制台，任意模型 {#terminal-bench-2-1-one-harness-any-model}

我们评估的是**智能体控制台（agent harness）**，而不是模型。因此，我们不是发布一个英雄式的分数，而是发布 Ante 在多个模型上的得分。对于**我们运行的每一个模型，Ante 都是排名第一的同模型智能体**：没有任何其他控制台在该模型上取得更高的分数。

来自[实时仪表盘](https://antigma.ai/eval)的亮点（截至 2026 年 6 月）：

| 模型 | 准确率 | 同模型排名 |
|---|---|---|
| GLM 5.2 | **74.6%** ±2.06 | #1 |
| MiMo V2.5 | 65.8% ±2.30 | #1 |
| DeepSeek V4 Pro | 65.8% ±2.25 | #1 |
| DeepSeek V4 Flash | 62.7% ±2.29 | #1 |
| MiniMax M3 | 62.1% ±2.33 | #1 |

有两点值得注意：

- **Ante + GLM 5.2 达到 74.6%**，使用一个开源模型就可以在公开的已验证排行榜中位列前 7。
- **Ante + DeepSeek V4 Pro 达到 65.8%**：与公开排行榜上使用前沿闭源模型的控制台组合具有相当的准确率，而整个 445 次实验的推理成本约为 36 美元。

一个好的控制台能够将前沿能力下放：它让开源模型能够完成你原本需要支付前沿模型价格才能完成的工作。

我们使用 [Terminal Bench](https://github.com/laude-institute/terminal-bench) 和 [Harbor](https://github.com/laude-institute/harbor) 作为我们主要的外部基准测试。Harbor 和 Terminal Bench 背后的团队是真正的研究人员 — 他们严谨、有原则，动机是把事情做对，而不是炒作。

为什么选择 Terminal Bench：
- **严谨。** 明确的任务规范，尽可能进行确定性评分，以及隔离的执行环境。
- **专注于核心能力。** 智能体能在真实的 shell 中完成真实的任务吗？阅读上下文、推理、行动、验证 — 这正是我们构建 Ante 的核心循环。

## 评估原则 {#evaluation-principles}

大部分魔力来自模型 — 但智能体控制台是人与 AI 之间的关键通道。

> 我们评估的是**智能体**以及它如何引导模型的力量 — 而不是模型本身。

**改进控制台，而不是提示词。** 当需要提高评估分数时，我们投资于智能体底座 — 运行时、编排、可靠性 — 而不是针对特定基准测试进行提示词工程。如果分数提高是因为系统真正变得更好了，那么这种提高是持久的。如果仅仅是因为我们调整了提示词，那它是脆弱的。
**尽早开始，从简单开始。** 一个从小规模真实失败案例中提取出的诚实评估集，胜过一个大规模人为构造的评估集。
**隔离和复现。** 每次评估运行都是从干净的环境开始。当分数下降时，我们就知道它反映了一个真实的退化。
