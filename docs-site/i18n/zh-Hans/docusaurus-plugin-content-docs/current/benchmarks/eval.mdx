# 基准评测

**我们紧跟前沿，您无需操心。** 新模型与更难的基准每隔几周就会出现。每个新的模型系列我们都会用同一套公开评测跑一遍，旧基准趋于饱和时就切换到更难的基准。您安装的 Ante 已经经过这两方面的检验，得分与推理成本都在同一页面公布。

## 我们的标准 {#our-standard}

我们以与前沿实验室自家智能体相同的官方标准要求 Ante，并让每个数字都可检验：

- **遵循官方限制。** 每个任务都保留基准自身的超时时间与沙箱资源限制，我们从不放宽。
- **评测真实分发的构建版本。** 每次评测均基于固定且公开可下载的 Ante 发行版运行，与 `ante update` 安装的二进制完全一致（例如 `0.3.5`）。没有专用于评测的分支，也没有针对 Benchmark 定制的专用提示词。
- **运行记录完全可审计。** 每个结果均链接其原始 [Harbor](https://github.com/harbor-framework/harbor) 运行记录，任何人都可以审阅每个 Trial 运行过程。
- **每次评测均在干净环境下启动。** 当得分下降时，我们知道它反映的是真实的回归问题。
- **结果实时持续发布。** 我们持续在 [antigma.ai/eval](https://antigma.ai/eval) 公布最新的评测数据。

> 我们评测的是 **Agent 底座** 激发并转化模型能力的效果 —— 而非仅仅评测模型自身。

当评测得分需要提升时，我们优化的是 Harness 本身：运行时架构、调度编排与可靠性。由系统变好带来的提升具有持久性，而针对某个 Benchmark 调优提示词得到的提升则脆弱易失。我们也坚持尽早评测、从简出发：基于真实失败案例提炼出的精简评测集，远胜于人工构造的庞大测试用例。

## Terminal-Bench 4.1：我们的主要基准 {#terminal-bench-41-our-primary-benchmark}

自 2026 年 11 月起，[Terminal-Bench 4.1](https://hub.harborframework.com/datasets/terminal-bench/terminal-bench/5?tab=leaderboard&leaderboard=4-1-0) 成为我们的主要基准。它是当下前沿实验室自家智能体同台排名的榜单：Claude Code、Codex 与 Antigravity CLI 均以各自最新模型上榜。

它也是更难的考验。Terminal-Bench 2.1 的榜首成绩已超过 85%。而在 4.1 的 66 个任务（其中 3 个需要 GPU）上，最高的官方验证成绩约为 71%（2026 年 11 月）。这段差距正是 Harness 能力得以体现的空间。

我们公布 Ante 搭配不同模型系列的成绩，而不是单一的明星数字。当前的代表性成绩：**Ante + DeepSeek V4.1 Flash 1017 达到 40.9%**，基于 Ante `0.3.5`，全量评测总推理费用约 $38（[原始运行记录](https://hub.harborframework.com/jobs/c7b8b27d-6759-4e5e-8ca7-3c7c25ff6a43)）。同一模型下 Claude Code 的官方验证成绩为 38.5%。

当前结果只在一处维护，即[实时看板](https://antigma.ai/eval)：我们评测过的每个模型，均与同模型的官方验证成绩并列展示。

## 为什么选择 Terminal-Bench {#why-terminal-bench}

我们将 [Terminal Bench](https://github.com/harbor-framework/terminal-bench-1) 与 [Harbor](https://github.com/harbor-framework/harbor) 作为主要的外部基准评测体系。Harbor 与 Terminal Bench 团队秉承严谨、扎实的研究精神，不追逐噱头。

- **严谨规范。** 任务规格明确，尽可能采用确定性评分，且在隔离环境中执行。
- **聚焦核心编码能力。** 智能体能否在真实的 Shell 环境中完成实际任务？读取上下文、推理、行动、验证：这正是 Ante 围绕其构建的核心闭环。
- **持续演进。** 随着模型不断进步，每个新版本都会提高门槛，我们也随之跟进。
