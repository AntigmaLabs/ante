# 基准测试

## 我们对发布的产品进行基准测试

我们的基准测试旨在接受检验：

- **我们对发布的产品进行基准测试。** 每次评估都针对一个已固定的、可公开下载的 Ante 发布版本运行，即与 `ante update` 安装的相同二进制文件（例如 `0.preview.43`）。没有仅用于评估的分支，也没有特定于基准测试的提示词。
- **运行是可审计的。** 每个结果都链接到其原始的 [Harbor](https://github.com/laude-institute/harbor) 运行记录，以便任何人都可以检查数据背后的试验过程。
- **约束条件是官方标准。** 所有试验均使用与官方 Terminal-Bench 排行榜相同的参数：89 个任务，每个任务 5 次试验，以及严格的超时和硬件限制。
- **结果是实时的。** 我们在 [antigma.ai/eval](https://antigma.ai/eval) 上持续发布结果。

## Terminal-Bench 2.1：统一控制框架（harness），任意模型

我们评估的是**代理控制框架（agent harness）**，而不是模型。因此，我们没有只发布一个单一的最佳数据，而是发布了 Ante 在多个模型上的得分。对于**我们运行的每个模型，Ante 都是同模型代理中的第一名**：没有其他控制框架在该模型上发布过更高的分数。

来自[实时仪表板](https://antigma.ai/eval)的亮点数据（截至 2026 年 6 月）：

| 模型 | 准确率 | 同模型排名 |
|---|---|---|
| GLM 5.2 | **74.6%** ±2.06 | #1 |
| MiMo V2.5 | 65.8% ±2.30 | #1 |
| DeepSeek V4 Pro | 65.8% ±2.25 | #1 |
| DeepSeek V4 Flash | 62.7% ±2.29 | #1 |
| MiniMax M3 | 62.1% ±2.33 | #1 |

两件值得注意的事情：

- **Ante + GLM 5.2 达到 74.6%** 将在使用开放权重模型的情况下，位列公开验证排行榜的前 7 名。
- **Ante + DeepSeek V4 Pro 达到 65.8%**：在公开排行榜上与前沿闭源模型的控制框架组合准确率相当，而在整个 445 次试验运行中，推理成本仅约 36 美元。

一个好的控制框架会将前沿能力推向更广阔的市场：它使得开放权重模型能够完成通常需要支付前沿模型价格才能完成的工作。

我们使用 [Terminal Bench](https://github.com/laude-institute/terminal-bench) 和 [Harbor](https://github.com/laude-institute/harbor) 作为我们的主要外部基准测试。Harbor 和 Terminal Bench 背后的团队是真正的研究人员 —— 他们严谨、有原则，其动机在于追求正确而非炒作。

为什么选择 Terminal Bench：

- **严谨。** 明确的任务规范，尽可能采用确定性评分，以及隔离的执行环境。
- **专注于核心能力。** 代理能否在真实的 shell 中完成实际任务？读取上下文、推理、行动、验证 —— 这正是我们构建 Ante 所围绕的核心循环。

## 评估原则

大部分的神奇之处来源于模型 —— 但代理控制框架（agent harness）是人与 AI 之间关键的导管。

> 我们评估的是**代理**以及它如何引导模型的能力 —— 而不是模型本身。

**改进框架，而不是提示词。** 当评估分数需要提升时，我们投资于代理的基础架构 —— 运行时、编排、可靠性 —— 而不是为特定基准测试进行提示词工程。如果由于系统真正变好而使分数提高，它就会保持提高。如果由于调整了提示词而使分数提高，它是脆弱的。

**尽早开始，简单起步。** 从实际失败案例中提取的小而真实的评估集胜过庞大且人为捏造的评估集。

**隔离并重现。** 每次评估运行都在一个干净的环境中开始。当分数下降时，我们知道这反映了真实的回归。
