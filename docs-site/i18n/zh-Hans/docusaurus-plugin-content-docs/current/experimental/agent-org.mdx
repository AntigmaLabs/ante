Ante 支持多种用于组织智能体协同工作的模式。每种架构都在自主性、协调开销和结果质量之间进行权衡。

## 独立模式 {#independent}

智能体在同一个问题上并行工作，彼此之间没有交互。聚合器会在最后综合它们的输出。

**最适合：** 多样化、独立视角能提高质量的任务（头脑风暴，冗余验证）。

```mermaid
flowchart TB
  classDef control fill:#e1f5ff,stroke:#4aa3df,color:#00324d;
  classDef agent fill:#fff4e6,stroke:#e0a96d,color:#4a2c00;
  classDef agg fill:#e6f3ff,stroke:#6ea8fe,color:#002b55;

  Start([开始]) --> Fanout{{并行扇出}}
  Fanout --> A1[智能体 1]
  Fanout --> A2[智能体 2]
  Fanout --> A3[智能体 3]

  A1 --> Barrier{{屏障 / 同步}}
  A2 --> Barrier
  A3 --> Barrier

  Barrier --> Agg[聚合器<br/>综合]
  Agg --> End([结束])

  class Fanout,Barrier control;
  class A1,A2,A3 agent;
  class Agg agg;
```

## 去中心化模式 {#decentralized}

智能体在平行的轮次中运行，阅读彼此先前的输出并提出修改建议。在经过固定轮数后，无需中央协调器即可形成共识。

**最适合：** 辩论式推理、同行评审或谈判等不应由单一权威主导的场景。

```mermaid
flowchart TB
  classDef control fill:#e1f5ff,stroke:#4aa3df,color:#00324d;
  classDef agent fill:#fff4e6,stroke:#e0a96d,color:#4a2c00;
  classDef state fill:#f3f4f6,stroke:#9ca3af,color:#111827;
  classDef decision fill:#ffe6f0,stroke:#f472b6,color:#4a044e;

  Start([开始]) --> Init[初始化]
  Init --> Board[(共享面板<br/>迄今为止的提案)]

  Board --> Fanout{{并行：阅读并提出}}
  Fanout --> A1[智能体 1<br/>阅读面板<br/>+ 提出增量]
  Fanout --> A2[智能体 2<br/>阅读面板<br/>+ 提出增量]
  Fanout --> A3[智能体 3<br/>阅读面板<br/>+ 提出增量]

  A1 --> Barrier{{屏障 / 同步}}
  A2 --> Barrier
  A3 --> Barrier

  Barrier --> Merge[将增量追加<br/>到面板]
  Merge --> Board

  Board --> Stop{{停止？<br/>轮数限制或收敛}}
  Stop -->|否| Fanout
  Stop -->|是| Consensus[从面板<br/>形成共识]
  Consensus --> End([结束])

  class Fanout,Barrier control;
  class A1,A2,A3 agent;
  class Board state;
  class Stop decision;
```

## 集中迭代模式 {#centralized-iterative}

一个中央编排器分解问题，并行分派智能体，评估它们的结果，并决定是继续改进还是结束。

**最适合：** 具有质量关卡的自上而下的规划能带来好处的复杂任务（带有代码审查的代码生成，多步骤研究）。

```mermaid
flowchart TB
  classDef control fill:#e1f5ff,stroke:#4aa3df,color:#00324d;
  classDef agent fill:#fff4e6,stroke:#e0a96d,color:#4a2c00;
  classDef orch fill:#e6f3ff,stroke:#6ea8fe,color:#002b55;
  classDef eval fill:#ffe6e6,stroke:#fb7185,color:#4c0519;
  classDef state fill:#f3f4f6,stroke:#9ca3af,color:#111827;
  classDef decision fill:#ffe6f0,stroke:#f472b6,color:#4a044e;

  Start([开始]) --> Setup[设置]
  Setup --> Workspace[(工作空间<br/>任务 + 结果)]

  Workspace --> Orch[编排器<br/>分解 / 细化计划]
  Orch --> Fanout{{并行：执行任务}}
  Fanout --> A1[智能体 1]
  Fanout --> A2[智能体 2]
  Fanout --> A3[智能体 3]

  A1 --> Barrier{{屏障 / 同步}}
  A2 --> Barrier
  A3 --> Barrier

  Barrier --> Write[将结果写入<br/>到工作空间]
  Write --> Workspace

  Workspace --> OrchEval[编排器<br/>评估质量]
  OrchEval --> Stop{{完成？}}
  Stop -->|否：改进| Orch
  Stop -->|是| Final[最终<br/>综合]
  Final --> End([结束])

  class Fanout,Barrier control;
  class A1,A2,A3 agent;
  class Orch orch;
  class OrchEval eval;
  class Workspace state;
  class Stop decision;
```

## 混合迭代模式 {#hybrid-iterative}

将集中式的编排与去中心化的同行评审改进相结合。编排器计划并分派智能体，然后智能体在对等轮次中相互改进对方的工作，之后再由编排器进行评估。

**最适合：** 需要结构化计划和同行反馈的高质量协作输出（协作写作，架构设计）。

```mermaid
flowchart TB
  classDef control fill:#e1f5ff,stroke:#4aa3df,color:#00324d;
  classDef agent fill:#fff4e6,stroke:#e0a96d,color:#4a2c00;
  classDef peer fill:#f0e6ff,stroke:#a78bfa,color:#2e1065;
  classDef orch fill:#e6f3ff,stroke:#6ea8fe,color:#002b55;
  classDef eval fill:#ffe6e6,stroke:#fb7185,color:#4c0519;
  classDef state fill:#f3f4f6,stroke:#9ca3af,color:#111827;
  classDef decision fill:#ffe6f0,stroke:#f472b6,color:#4a044e;

  Start([开始]) --> Setup[设置]
  Setup --> Workspace[(工作空间<br/>草稿 + 笔记)]

  Workspace --> Orch[编排器<br/>规划]
  Orch --> Fanout1{{并行：起草}}
  Fanout1 --> A1[智能体 1]
  Fanout1 --> A2[智能体 2]
  Fanout1 --> A3[智能体 3]

  A1 --> Barrier1{{屏障 / 同步}}
  A2 --> Barrier1
  A3 --> Barrier1

  Barrier1 --> Write1[将草稿写入<br/>到工作空间]
  Write1 --> Workspace

  Workspace --> Fanout2{{并行：同行改进}}
  Fanout2 --> PR1[同行 1<br/>利用其他人的工作进行改进]
  Fanout2 --> PR2[同行 2<br/>利用其他人的工作进行改进]
  Fanout2 --> PR3[同行 3<br/>利用其他人的工作进行改进]

  PR1 --> Barrier2{{屏障 / 同步}}
  PR2 --> Barrier2
  PR3 --> Barrier2

  Barrier2 --> Write2[将改进结果写入<br/>到工作空间]
  Write2 --> Workspace

  Workspace --> OrchEval[编排器<br/>评估质量]
  OrchEval --> Stop{{完成？}}
  Stop -->|否：继续| Orch
  Stop -->|是| Final[最终<br/>综合]
  Final --> End([结束])

  class Fanout1,Fanout2,Barrier1,Barrier2 control;
  class A1,A2,A3 agent;
  class PR1,PR2,PR3 peer;
  class Orch orch;
  class OrchEval eval;
  class Workspace state;
  class Stop decision;
```

## 选择架构 {#choosing-an-architecture}

| 架构 | 协调方式 | 迭代方式 | 使用时机 |
|---|---|---|---|
| **独立模式** | 无 | 单次通过 | 需要多样化的视角且无需交互开销时 |
| **去中心化模式** | 点对点 | 固定轮数 | 智能体应该在没有中央权威的情况下自我组织时 |
| **集中迭代模式** | 编排器驱动 | 质量关卡 | 需要带有评估检查点的结构化任务分解时 |
| **混合迭代模式** | 编排器 + 同行 | 质量关卡 | 既需要自上而下的规划，又需要自下而上的同行改进时 |
