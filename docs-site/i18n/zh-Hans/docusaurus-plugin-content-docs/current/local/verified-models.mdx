在[离线模式](/local/offline)选择器中的**已验证模型 (Verified models)** 列表是精心挑选的：这些是从 Hugging Face 下载的、且具有已知内存需求的、并在 Ante 智能体循环上测试过的 GGUF 构建。每个模型具有以下两种状态之一：

- **已评估 (Evaled)** — 运行了完整的公开基准测试：与我们的[前沿模型结果](/benchmarks/eval)采用了相同的 Terminal-Bench 2.1 测试框架、固定的构建以及可审计的 Harbor 运行。测试数据公开于 [antigma.ai/eval](https://antigma.ai/eval)。
- **已验证 (Verified)** — 兼容性经过测试：模型可以正常加载，聊天模板能够解析，并且在 Ante 的智能体循环中工具调用工作正常。尚未跑完全部评估。

一旦基准测试运行完成，模型将从“已验证”升级为“已评估”。

## 添加您的自定义模型 {#add-your-own}

在启动时，Ante 会将 `~/.ante/verified_models.json` 合并至内置列表之上。如果某个条目的 `filename` 与内置模型匹配，它将覆盖内置版本；新的 `filename` 会被追加到列表中。

```json
{
  "models": [
    {
      "name": "我的自定义模型",
      "repo": "username/repo-name",
      "filename": "model-Q4_K_M.gguf",
      "context_window": 32768,
      "file_size_mb": 5000,
      "kv_cache_bytes_per_token": 131072,
      "support_vision": false
    }
  ]
}
```

| 字段 | 描述 |
|---|---|
| `name` | 在模型选择器中的显示名称 |
| `repo` | 用来下载文件的 Hugging Face 仓库 |
| `filename` | 仓库内的 GGUF 文件名（同时也是合并键） |
| `context_window` | 模型支持的最大上下文长度（Token 数） |
| `file_size_mb` | 下载大小，用于估算内存 |
| `kv_cache_bytes_per_token` | 上下文中每个 Token 对应的 KV 缓存增量，用于估算内存 |
| `support_vision` | 该模型是否支持图像输入（可选） |
