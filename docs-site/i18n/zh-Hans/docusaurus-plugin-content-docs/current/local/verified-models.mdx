[离线模式](/local/offline)选择器中的 **Verified models（推荐验证模型）** 是经过 Ante 智能体循环兼容性测试的 GGUF 构建，可从 Hugging Face 下载，并提供内存需求估算。

兼容性验证与基准评测是不同的检查：验证确认模型加载、对话模板和工具调用可用；基准成绩则应以注明具体构建与公开运行记录的[评测页](/benchmarks/eval)为准。

## 查看当前推荐模型 {#current-list}

内置列表会随 Ante 版本更新。请在 `/offline-mode` 中打开 **Verified models**，或查看当前安装版本提供的模型：

```bash
ante offline list
ante offline list --json
```

输出同时列出已发现的本地 GGUF 文件，并显示下载大小、最大上下文、内存适配估算与默认模型标记。JSON 中的 `reference` 可直接用于 `ante offline use` 或 `--offline-model`，无需猜测文件名。

```bash
ante offline use Qwen3.8-27B --context 32768
ante --offline-model
```

“最大上下文”是模型支持的上限，不是建议加载窗口。Ante 默认将上下文限制为 32K 以控制内存需求；可通过[模型偏好](/local/offline#model-preferences)调整，或在没有已保存偏好时设置 `ANTE_OFFLINE_CONTEXT`。选择模型前请查看实际内存适配估算。

如果之前选择的模型已不在内置列表中，可通过本地 GGUF 路径继续使用，或按下文添加自己的验证条目。

历史评测：Qwen3.6 27B 在 89 个 Terminal-Bench 2.1 任务、共 445 次 Trial 中取得 **56.2%** 的准确率。该结果仍可在[评测页](/benchmarks/eval#terminal-bench-21)查看，但不表示模型仍在当前内置列表中。

## 自定义添加验证模型 {#add-your-own}

Ante 在启动时会自动将 `~/.ante/verified_models.json` 合并到内置推荐列表中。`filename` 匹配内置条目的条目将覆盖内置预设；新文件名会自动追加。

```json
{
  "models": [
    {
      "name": "My Custom Model",
      "repo": "username/repo-name",
      "filename": "model-Q4_K_M.gguf",
      "context_window": 32768,
      "file_size_mb": 5000,
      "kv_cache_bytes_per_token": 131072,
      "support_vision": false
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `name` | 在模型选择器中展示的名称 |
| `repo` | 文件下载来源的 Hugging Face 仓库 |
| `filename` | 仓库内的 GGUF 文件名（同时也是合并匹配的 Key） |
| `context_window` | 模型支持的最大上下文（Token 数） |
| `file_size_mb` | 下载大小，以 MiB 向上取整，用于内存估算 |
| `kv_cache_bytes_per_token` | 每个上下文 Token 的 KV 缓存增长量，用于内存估算 |
| `support_vision` | 模型是否支持图片输入（可选） |
