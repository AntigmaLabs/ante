# 在设计上完全独立 {#self-contained-by-design}

Ante 是一个约 15MB 的单一二进制文件，并自身管理着推理引擎。只要提供一个 GGUF 文件，您就拥有一套在自有硬件上运行的完整编码智能体：不需要 API 密钥，不需要账户，所有的模型调用请求都不会离开您的机器。

本地运行（Local）是使用 Ante 的第一级方式（first-class way）。托管提供商（hosted）与本地提供商并存于相同的目录中，运行相同且完整的提示词（prompt）和工具栈，同时接受完全相同的[公开基准测试](/benchmarks/eval)。您可以为每次会话根据任务需要来决定使用哪种模型。

## 选择您的拓扑结构 {#pick-your-topology}

| 拓扑结构 | 形式说明 | 适用场景 |
|---|---|---|
| **全前沿模型 (All frontier)** | 仅使用托管提供商 | 您需要巅峰级的模型能力，并且拥有良好的网络连接和预算 |
| **混合模式 (Mixed)** | 本地与托管模型并存，在每次会话间或对话中途切换 | 部分工作具有隐私敏感性或属于高频大批量任务，而另一部分工作则需要前沿模型 |
| **全本地模型 (All local)** | 内置引擎服务于一切任务 | 隔离（Air-gapped）环境、严格的隐私要求、零边际成本 |

## Ante 如何对待本地模型 {#how-ante-treats-local-models}

**与其他提供商一视同仁。** 任何提供兼容 OpenAI 接口（如 Ollama、vLLM、LM Studio 或您自行搭建的）本地服务器，都可以通过相同的 `catalog.json` 机制注册，与托管提供商无异。没有特殊处理，未来也无需重构迁移。请参阅[提供商](/usage/providers#add-a-local-provider-with-no-auth)与[目录参考](/reference/catalog-reference)。

**原生集成。** Ante 不仅仅是能够接受并使用基础 URL（base URL）。[离线模式](/local/offline) 自身管理了 llama.cpp：使用固定的、通过校验和验证的、与您的硬件匹配的构建版本（在 Apple 芯片上为 Metal，Linux 上为 CUDA、Vulkan 或 CPU），全盘扫描发现 GGUF 模型，加载前估算内存，实时加载进度，并在 TUI 中完成对服务器生命周期的管理。一份[已验证模型列表](/local/verified-models) 在您下载 17 GB 之前就告诉您哪些模型表现优秀。更倾向于您自己的构建版本或启动标志（flags）？请参阅[自定义引擎](/local/custom-engines)。

**原生智能体推理，正在进行中。** 终局方案（endgame）是在智能体进程内部构建一个推理引擎，并且针对智能体实际调用模型的方式进行调优。本地模型正在成为许多工作负载下的首选基础，基准测试数据足以支持这一点。请查看[实验性预览](/experimental/agent-native-inference)。

## 混合使用本地与前沿模型 {#mixing-local-and-frontier}

当离线模式加载一个模型后，Ante 会将其注册为 `local` 提供商：在目录中以普通的兼容 OpenAI 的条目存在，紧邻 Anthropic 或 OpenAI。由此，混合使用就是一套常规的提供商机制：

- **会话中途切换。** 在 TUI 中使用 `/model` 即可切换提供商与模型，无需重启。您可以先使用前沿模型打草稿，然后为处理敏感的仓库切换至本地模型，然后再切换回来。
- **针对单次调用进行指定。** `ante --provider local` 可以让脚本或无头任务（headless job）针对已加载的模型运行，而其他会话继续使用托管提供商。
- **跨客户端共享同一模型。** `ante serve --offline-model <path>` 一次加载模型后，即可服务所有连接进来的客户端，并且任意会话均可[连接到已经在您机器上运行的 llama 服务器](/local/existing-servers)（将自动扫描 8080-8179 端口）。
- **为子智能体提供轻量模型。** 一个[子智能体（subagent）](/extend/subagents) 可以通过其前缀元数据（frontmatter）中的 `model:` 固定它所使用的模型 id，这样探索或搜索型的智能体可以运行在一个比主循环更小的模型上。

一项需知晓的界限：一次会话在同一时刻只能与一个提供商对话。切换是瞬间的，但子智能体在其父会话的提供商上运行，因此您目前无法在同一个会话中将主循环路由到前沿提供商，而把子智能体路由到 `local`。

## 您可以验证的数据 {#numbers-you-can-check}

我们对本地模型的基准测试与前沿模型采取同样严格的标准：相同的测试套件（harness）、相同的固定公共构建版本、相同的可审计 Harbor 运行过程。作为一个 17 GB 的下载文件，Qwen3.6 27B 在 Terminal-Bench 2.1 上跨越 445 次测试得出了 **56.2%** 的成绩 — 数据实时公布于 [antigma.ai/eval](https://antigma.ai/eval)，完整的精选列表请参见[已验证模型](/local/verified-models)。
