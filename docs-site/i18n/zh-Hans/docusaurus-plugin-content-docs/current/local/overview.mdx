# 独立自包含设计

Ante 是一个自包含的单二进制程序（压缩下载仅 ~15MB），能够自主管理其内置的推理引擎。只需准备一个 GGUF 模型文件，即可在自有硬件上拥有完整的编码智能体：无需 API 密钥、无需账号，所有模型调用绝不离开本地机器。

:::note 隐私边界
本地推理确保模型请求与响应完全留在本地硬件内。Ante 应用程序本身的遥测数据与模型通信相互独立；对于完全禁止上报指标的场景，可设置 `ANTE_TELEMETRY=off`。这不会影响本地日志文件的记录。详见[遥测配置](/configuration/preference#telemetry)。
:::

本地运行是 Ante 的一等公民体验。托管云端提供商与本地模型存在于同一个目录系统，运行完全一致的提示词与工具链，并经受相同的[公开基准评测](/benchmarks/eval)。您可以按任务随时选择最适合的运行模式。

## 选择部署拓扑

| 拓扑架构 | 架构形态 | 适用场景 |
|---|---|---|
| **全前沿云端（All frontier）** | 仅使用云端托管模型提供商 | 追求顶尖智能上限，具备良好网络连接与预算 |
| **混合模式（Mixed）** | 本地模型与云端模型并存，在会话中按需切换 | 部分任务涉及高度隐私或高频调用，部分复杂任务依赖前沿模型 |
| **完全本地（All local）** | 内置推理引擎完全承载所有调用 | 离网隔离环境、严苛的数据隐私合规、零边际 Token 成本 |

## Ante 对本地模型的支持体系

**平等视作标准提供商。** 任何提供兼容 OpenAI 接口的本地服务端（Ollama、vLLM、LM Studio、自建服务等），均通过与云端提供商相同的 `catalog.json` 机制接入。无需特殊定制逻辑，后续也无需复杂迁移。详见[添加本地提供商](/usage/providers#add-a-local-provider-with-no-auth)及[目录参考手册](/reference/catalog-reference)。

**深度原生集成。** Ante 不仅支持配置一个基础 URL。[离线模式](/local/offline)能自动管理 llama.cpp 运行时：匹配硬件架构的固定校验构建版本（Apple Silicon Metal、Linux CUDA / Vulkan / CPU）、全盘 GGUF 文件自动扫描发现、加载前内存显存智能预估、实时加载进度展示，以及在 TUI 中直接控制服务端生命周期。[推荐模型列表](/local/verified-models)让您在下载十数 GB 权重前明确其评测表现。若希望使用自定义构建或启动参数，请参阅[自定义引擎](/local/custom-engines)。

**智能体原生推理研发中。** 我们的终极目标是将推理引擎直接嵌入智能体进程，针对智能体调用大模型的行为特征深度调优：跨轮次前缀缓存复用、工具调用的约束采样解码、子智能体间的批量并发推理。我们通过开源项目 [nanochat-rs](https://github.com/AntigmaLabs/nanochat-rs)（一个纯 Rust 实现的精简推理核心）公开推进探索。详见[智能体原生推理](/experimental/agent-native-inference)。

## 灵活混合本地与前沿模型

当离线模式加载模型后，Ante 会将其注册为 `local` 提供商：与 Anthropic 或 OpenAI 并列的标准 OpenAI 兼容目录项。在此基础上，切换体验顺畅自然：

- **会话中随时切换。** 在 TUI 中输入 `/providers` 无需重启即可切换提供商与模型。在开发常规代码时使用前沿模型，在处理敏感仓库时一键切换至本地模型。
- **命令行按需指定。** `ante --offline-model <file>` 针对本地模型执行脚本或无头任务，其他会话继续使用云端提供商。
- **多客户端共享同一本地模型。** `ante serve --offline-model <path>` 加载一次即可供所有接入客户端复用，且任何会话均可直接[连接到已运行的 llama 服务](/local/existing-servers)（自动扫描 8080-8179 端口）。
- **为子智能体分配轻量模型。** [Subagent 子智能体](/extend/subagents)可通过 Frontmatter 中的 `model:` 单独指定模型 ID，使搜索或代码探索子智能体运行在更小、更快的模型上。

## 真实可验证的基准数据

我们以评测前沿模型相同的严谨标准评测本地模型：相同的测试集、固定公开版本、可审计的 Harbor 运行记录。Qwen3.6 27B（17 GB 下载）在 Terminal-Bench 2.1 跨 445 次 Trial 评测中取得 **56.2%** 的准确率 —— 实时数据见 [antigma.ai/eval](https://antigma.ai/eval)，完整推荐模型见[推荐验证模型](/local/verified-models)。
