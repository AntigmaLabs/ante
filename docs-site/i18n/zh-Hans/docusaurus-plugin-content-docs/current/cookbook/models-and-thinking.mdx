# 模型、提供商与思考

Ante 允许您在会话中途切换模型、提供商和推理级别 — 无需重启。

## 选择模型

在 TUI 中输入 `/model` 以打开模型选择器。您将看到按提供商分组的可用模型。使用方向键导航，按 Enter 键确认。

<img src="/assets/cookbook/model.gif" alt="Selecting a model and provider with /model" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

在同一个界面中，您可以：

- **切换提供商** — 按 `Tab` 键在 Anthropic、OpenAI、Gemini、Grok 等之间切换
- **调整思考预算** — 对于支持扩展思考的模型（例如具备思考能力的 Claude），配置模型在响应之前应进行多少推理

:::tip
您也可以通过 CLI 标志设置默认模型和提供商：`ante --provider openai --model gpt-5.5`，或在您的[偏好设置](/configuration/preference)中配置默认值。
:::

如果您选择了一个提供商但未指定模型，Ante 将默认使用该提供商功能最强大的模型，并在后台静默使用更轻量、更便宜的模型执行诸如总结所获取网页等工作 — 请参阅[重量级](/reference/catalog-reference#weight-classes)。支持视觉功能的模型会被自动检测，因此您可以将图像直接拖放到聊天中。
