# 提供上下文：文件与文件夹

通过在提示词中直接引用文件和目录，为智能体提供其所需的确切上下文。

## 使用 @ 提及

输入 `@` 后跟文件或目录路径。Ante 会在您输入时显示搜索下拉列表 — 按 Tab 键自动补全，然后按 Enter 键确认。

<img src="/assets/cookbook/files.gif" alt="Adding file context with @ mentions" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

- **`@path/to/file.rs`** — 将完整的文件内容嵌入到您的消息中
- **`@path/to/dir/`** — 嵌入目录树列表

这可确保智能体准确看到您所询问的代码，而无需猜测或搜索。

:::tip
如果您粘贴多个文件路径，Ante 会为了方便而自动为它们添加 `@` 前缀。您可以在单个提示词中引用任意数量的文件。
:::
