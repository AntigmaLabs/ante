# 中断与引导

不要等待智能体在错误的路径上走完。Ante 允许您随时中断并重定向。

## 中断

在智能体生成内容时按 `Ctrl+C` 立即停止当前回合。当没有弹出窗口打开时，按 `Escape` 键也可以中断。智能体将保留截至该时刻的任何上下文，因此您可以通过后续消息纠正路线 — 无需重新开始。

这不仅可以节省时间，还能节省 token，特别是当您在早期发现智能体方向错误时。

## 无需中断即可引导

您不必停止当前回合来重定向。在智能体工作时输入消息并按 `Enter` 键 — 它不会开启一个新回合，而是被**排队**。然后：

- 按 `Ctrl+S` 进行**引导**：将排队的消息刷新到正在运行的回合中作为实时指导，而不会中断它。
- 或者什么都不做 — 当前回合结束后，排队的消息将自动提交。

引导功能保持了智能体的势头，同时轻推其方向，这在它方向正确但遗漏了细节时非常理想（例如：“同时更新测试”，“使用现有的辅助函数”）。

## 命令历史记录

在输入区按向上（`Up`）方向键，以循环浏览您之前的提示词。这使得在中断后重新发送或调整最近的消息变得容易。

:::tip
您也可以使用 `Ctrl+R` 通过反向增量搜索（reverse-i-search）在您的完整提示词历史记录中进行搜索 — 当您想要查找会话早期内容时，这非常方便。
:::
