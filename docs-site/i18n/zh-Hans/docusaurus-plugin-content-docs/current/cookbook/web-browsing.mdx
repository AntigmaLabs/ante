# 网页浏览与阅读文档

Ante 可以搜索网页并从 URL 获取内容，让您无需离开终端即可提取文档、查找 API 或研究主题。

## 搜索网页

只需自然地询问 — Ante 会使用其网页浏览工具来找到您所需要的内容：

<img src="/assets/cookbook/webbrowse.gif" alt="Ante performing a web search" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

智能体能够：

- **搜索网页**获取文档、示例和答案
- **获取 URL**直接读取其内容（例如，API 文档、发布说明、博客文章）
- **总结**结果并将它们整合到对话中

当您在使用不熟悉的库，或者需要查看工具或 API 的最新文档时，这尤其有用。

:::note
获取 URL（`WebFetch`）默认开启。完整的网页**搜索**（`WebSearch`）通过提供商的原生搜索运行，因此仅在使用支持该功能的提供商（Anthropic、OpenAI、Gemini、Grok、OpenRouter、Antix 或阿里编码计划）时可用。在这些提供商上它会自动启用 — 无需标志；在其他提供商上则不提供。请参阅[工具参考](/reference/tools-reference#websearch)。
:::

:::tip
您也可以从命令行将网页内容管道输送（pipe）给 Ante：`curl https://example.com/docs | ante -p "summarize this"`。
:::
