不带任何提示词直接启动 Ante 即可进入交互式 TUI 界面：

```bash
ante
```

## 概览

Ante 的 TUI 基于 [ratatui](https://ratatui.rs/) 构建，在终端中直接提供现代化的富文本对话界面。采用内联渲染（最多 24 行）并以约 100fps 的防抖帧率渲染，确保极致流畅的交互体验。

## 核心特性

### 聊天交互界面

主视图显示您与智能体之间的实时对话。在底部输入框中键入提示词并按 Enter 发送。智能体的回复以流式 Markdown 实时呈现。

Markdown 渲染原生支持 LaTeX 数学公式：`$...$`、`$$...$$`、`\(...\)` 或 `\[...\]` 中的表达式会自动转换为终端 Unicode 优雅呈现（如 `\alpha` → `α`，`x^2` → `x²`，`\frac{1}{2}` → `½`），并支持 `aligned` 和 `pmatrix` 等多行数学矩阵排版。

思考推理过程在主对话流中保持折叠。无论模型思考多久，当前轮次均显示为一行简洁指示器：

```
✻ Thinking… (ctrl+o expand)
```

当思考内容正在流式接收时，符号会呈现动态呼吸动画；流式结束后变为静态。如果同一轮次中经历了“思考 → 调用工具 → 再次思考”，则会为每个片段显示对应标记。完整的思考独白可随时在[完整记录视图（Transcript View）](#transcript-view)中实时查看。

### 工具审批（Tool Approval）

当智能体尝试调用需要授权的工具（如 `Bash` 或 `Write`）时，界面会弹出交互式审批菜单。使用数字键或方向键 + Enter 进行确认：

- **Yes** — 仅允许本次单次调用
- **Yes, allow … for this session** — 在当前会话中保持允许（具备[智能作用域泛化](/configuration/permission#session-grants)）
- **Yes, always allow … (save to settings)** — 将允许规则永久持久化到 `settings.json`
- **No** — 拒绝本次调用；智能体会调整策略寻找其他方案

在决定前按 `Tab` 键可预览生成的代码 Diff 或请求详细参数。

### 全屏 Diff 代码审查视图

当智能体提议修改文件时，Ante 会切换至全屏 Diff 视图。您可以在批准前逐行审查变动。Diff 视图提供行号槽、全宽增删背景色块以及顶部的 `+N -M` 改动统计。

### 完整记录视图（Transcript View）

按 `Ctrl+O` 打开全屏完整记录视图：展示完整的历史对话记录以及展开的工具调用输出（包含主聊天视图中被截断的长文本）。使用 `j`/`k` 或 `PgUp`/`PgDn` 滚动，使用 `g`/`G` 快速跳转到顶部/底部，按 `Ctrl+O` 或 `q` 退出。

在主聊天视图中，连续的静默工具调用（如 Bash、Read、Grep、Glob、WebFetch、WebSearch 及 MCP 工具）默认会被折叠为单个紧凑活动块。调用执行时展示计数、参数与耗时；完成后折叠为汇总信息（如 `Ran 2 shell commands, searched for 3 patterns`）。成功的文件读取和失败调用会单独展开在下方 —— 读取显示为 `Read (src/main.rs) ·110 lines`，失败调用显示为红色 `Failed` 标题及其错误原因。Edit、Write 和 Agent 调用始终保持独立卡片，且全屏记录视图始终保留所有详细调用与输出。可以在 `/config` 中开关 **Group tool activity** 或在 `~/.ante/settings.json` 中配置 `"group_tool_activity": false`。

在执行会话压缩后（通过 `/compact` 或[自动压缩](/configuration/preference#settings-file)），主视图显示折叠的 `* Compacted` 标记；完整记录视图则展示模型生成的完整上下文摘要。

### 文本选择与复制

全屏视图（包括完整记录视图、[Diff 视图](#diff-view)和 `/diff` 输出）捕获鼠标滚轮事件，并内置高精度文本选择机制：拖拽选中文本并在松开鼠标时自动复制，底部状态栏会提示 `copied N lines`。双击选中单词（智能包含 `_-./~+@#$%&=:`，确保文件路径或完整 URL 不被截断），三击选中整行。拖拽到可视区域顶部或底部可自动继续滚动选择。

复制时会自动将软折行的文本拼接还原为完整单行，确保长命令和 URL 粘贴时保持完整。复制内容会同步写入操作系统剪贴板，并通过 OSC 52 转义序列分发（因此支持在 SSH 远程会话和 tmux 中跨端复制）。点击空白区域可清除选区。

内联主聊天视图不拦截鼠标，您可以继续使用系统终端自带的原生选择和复制功能。

### 模型与提供商切换

使用内置选择器在会话中随时切换模型或提供商，无需重启 Ante。

### 主题切换

Ante 提供丰富的主题系统，支持在主题弹窗（`/theme` 或 `Ctrl+T`）中随时选择喜欢的外观。

## 斜杠命令

输入 `/` 即可触发内置命令（如 `/models`、`/resume`、`/compact` 等）。完整命令列表请参见[斜杠命令手册](/usage/slash-commands)。

## 会话消耗统计（/usage）

输入 `/usage` 打开会话消耗面板：按模型细分显示 Token 用量、全会话缓存命中率以及 Turn 和模型调用次数。

```
Usage by model:
  claude-opus-5:  5.0k input, 3.2k output, 1.1m cache read, 45.0k cache write
  gpt-5.1:  900 input, 80 output

Cache hit rate:  95%
Turns: 12 · Model calls: 2
```

数据分为四类：`input` 仅统计未经缓存的输入 Token，已缓存部分分别计为 cache reads 和 cache writes。缓存命中率为 cache reads 占总输入 Token 的百分比。

## 目标导向型会话

使用 `/goal <条件>` 开启持续自主闭环工作，直到满足验收条件。详见[目标导向会话](/usage/goal-sessions)。

## 会话恢复（Session Resume）

Ante 会自动将所有会话持久化到磁盘中。输入 `/resume` 即可随时恢复历史会话。

### 工作流程

1. 输入 `/resume` 打开会话选择器
2. 浏览当前工作目录下的历史会话 —— 每条记录显示首条消息、所用模型、消息总数与相对时间
3. 按 **Enter** 选择恢复，按 **Esc** 取消
4. 按 **d**（或 **Delete**）删除选中的历史会话 —— 再次按 **d** 确认。当前正在活跃的会话无法删除

恢复会话时，Ante 会：
- 完整还原历史对话记录
- 重新发现当前项目目录中的 Agent 和 Skills（除非会话是以 `--no-skills` 启动）
- 刷新系统提示词与工具定义（确保新特性立即可用）
- 回放最近 200 条事件以重建 TUI 对话视图

会话保存在 `~/.ante/sessions/{session_id}/`，采用原子写入确保崩溃安全性。

:::tip
也可以在终端命令行中通过 `ante --resume <SESSION_ID>`（或 `-r`）直接恢复会话。TUI 会话退出时会自动打印当前会话 ID。
:::

### 从 Claude Code 或 Codex 迁移接管

如果在当前目录中 4 小时内曾运行过 Claude Code 或 Codex 会话，Ante 启动时会显示一行轻量提示，询问是否直接接管继续。

内置技能 `/resume-claude` 与 `/resume-codex` 可随时调用：它们会在磁盘上定位第三方会话记录，以纯数据方式解析，重构任务目标、当前进度及下一步计划 —— 并在继续工作前与您确认。

配合 `/import-claude`，还可以将 Claude Code 在当前目录下的项目记忆复制到 Ante 的[项目记忆库](/extend/memory#importing-claude-code-memory)中。

## @ 语法引用文件

在输入框中输入 `@` 可直接引用文件或目录，支持实时自动补全：

- `@path/to/file.rs` — 将文件全文嵌入消息
- `@path/to/dir/` — 嵌入目录树状列表

:::tip
直接粘贴多个文件路径时，Ante 会自动为其添加 `@` 前缀。
:::

## Bash 模式

在输入内容最前面加上 `!` 即可直接作为本地 Shell 命令执行，而不会发送给大模型：

```
!git status
!cargo build
```

命令会在您当前的登录 Shell（`$SHELL -lc`，回退为 `/bin/sh`）中从当前工作目录执行，超时上限为 120 秒。执行结果会在对话流中展示，并自动作为上下文提供给下一轮智能体对话。

:::note
Bash 模式在本地直接执行，无需权限审批（输入 `!` 即代表授权）。这与智能体自主发起的 `Bash` 工具调用不同，后者的执行依然受权限系统约束。
:::

## 终端会话管理（tmux）

智能体可以通过常驻的命名 tmux 会话驱动交互式程序（如本地 Dev Server、REPL、SSH 或其他 CLI 智能体），使用普通的 `tmux` 命令配合内置的 `tmux` 技能进行控制。会话位于 `ante-` 命名空间下，在 Ante 重启后依然保持存活。退出 TUI 时不会杀死后台会话。

输入 `/term <name> [args...]` 可打开对应的终端视图（如果不存在则自动创建）。如果 `<name>` 是系统 PATH 中的可执行程序，新创建的会话会自动运行 `<name> [args...]`（例如 `/term claude --continue`）。若会话已存在则直接附加（Attach）。再次运行 `/term <name>` 会分离终端视图并保持后台程序继续运行。

单独输入 `/term` 会打开所有运行中 Ante 会话的选择列表。按 **Enter** 附加/分离，连续按两次 **d** 或 **Delete** 杀死会话，或选择 **new terminal** 创建新会话。

终端分割窗口支持 tmux、zellij、WezTerm、kitty、Ghostty 1.3+ 和 iTerm2。若无法分屏则会自动拉起独立系统终端窗口。

该功能依赖系统已安装 `tmux`。

## 下一轮提示词智能预测建议

当一轮对话结束且输入框为空时，Ante 会在后台轻量预测可能的下一步提示词，并以半透明虚字展示。按 `Tab` 键即可采纳并填入输入框进行编辑修改；按其他任意键会自动取消该建议。

预测使用最廉价的模型在关键路径之外异步生成，绝不拖慢会话响应速度。默认开启；可在 `~/.ante/settings.json` 中配置 `"ambient_prompt_suggestion": false` 关闭。

## 动态思考状态语（Thinking Phrase）

在输入较长提示词时，Ante 会在后台预生成与任务相关的简短状态语作为加载动画的标签。默认开启；可在 `~/.ante/settings.json` 中配置 `"ambient_thinking_phrase": false` 关闭。
