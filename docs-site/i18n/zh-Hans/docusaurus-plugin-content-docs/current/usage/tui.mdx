---
title: "交互式 TUI"
description: "使用 Ante 丰富的终端用户界面"
---

在没有提示词的情况下启动 Ante 以进入交互式 TUI：

```bash
ante
```

## 概览

TUI 是使用 [ratatui](https://ratatui.rs/) 构建的，直接在你的终端中提供了丰富的聊天界面。它内联渲染（最多 24 行），并使用大约 100fps 的防抖渲染以实现平滑输出。

## 核心功能

### 聊天界面

主视图显示了你和智能体之间的对话。在输入区输入你的提示词，然后按 Enter 键发送。智能体的回复会以 markdown 格式实时流式显示。

### 工具审批

当智能体想要执行需要审批的工具（如 `Bash` 或 `Write`）时，你会看到一个审批提示。使用数字键或方向键 + Enter 键选择一个选项：

- **Yes** — 允许此次调用
- **Yes, allow … for this session** — 在本次运行的剩余时间里授予权限（[作用域化](/configuration/permission#session-grants)，非一揽子授权）
- **Yes, always allow … (save to settings)** — 并在 `settings.json` 中持久化一条允许规则
- **No** — 拒绝它；智能体会调整其方法

在决定之前按 `Tab` 预览提议的差异（diff）或请求详细信息。

### 差异视图

当智能体提议文件编辑时，Ante 会切换到备用屏幕上的全屏差异视图。你可以在批准前审查确切的更改。

### 模型和提供商选择

使用内置的选择器在会话期间切换模型或提供商，而无需重启。

### 主题选择

Ante 包含一个用于统一样式的主题系统。通过主题对话框选择一个主题。

## 斜杠命令

TUI 支持内置的斜杠命令用于常见操作：

| 命令 | 描述 |
|---|---|
| `/clear` | 清除对话历史 |
| `/init` | 分析项目并创建一个 `AGENTS.md` 文件 |
| `/exit` | 退出 Ante |
| `/compact` | 总结对话历史以释放上下文窗口 |
| `/theme` | 打开主题选择对话框 |
| `/diff` | 显示 git diff（包括未跟踪的文件） |
| `/connect` | 使用 OAuth 登录（API 密钥会自动检测） |
| `/model` | 选择模型和已连接的提供商 |
| `/providers` | 为当前会话选择一个可用的提供商 |
| `/offline-mode` | 使用内置推理引擎运行本地模型 |
| `/pty` | 切换嵌入式终端面板（`Ctrl+P` 切换焦点） |
| `/welcome` | 显示欢迎/引导对话框 |
| `/resume` | 恢复此目录中之前的会话 |
| `/statusline` | 配置状态行 |
| `/mcp` | 检查和管理配置的 [MCP 服务器](/extend/mcp) |

:::note
某些命令是“可见的”（出现在对话历史中），其他命令是“静默的”（执行时不添加到历史中）。`/clear`, `/init`, `/exit` 和 `/compact` 是可见的；其余都是静默的。
:::

技能（Skills）也会作为带有作用域指示符的斜杠命令出现：`[p]` 表示项目级，`[u]` 表示用户级，`[s]` 表示系统级技能。

## 会话恢复

Ante 会将每个会话持久化到磁盘。使用 `/resume` 从你离开的地方继续之前的对话。

### 工作原理

1. 输入 `/resume` 打开会话选择器
2. 浏览限定在当前工作目录的会话——每个条目显示第一条消息、模型、消息数量和相对时间
3. 按 **Enter** 选择，或按 **Esc** 取消

恢复时，Ante 会：
- 恢复完整的对话历史
- 重新发现项目目录中的智能体和技能
- 刷新系统提示词和工具定义（以便新功能可用）
- 重放最多 200 个最近的事件，以便 TUI 重建对话视图

会话存储在 `~/.ante/sessions/{session_id}/` 中，并采用原子写入以保证崩溃安全。

:::tip
你也可以在 TUI 或无头模式下通过 CLI 使用 `ante --resume <SESSION_ID>`（或 `-r`）进行恢复。当 TUI 会话退出时会打印会话 ID。
:::

## 键盘快捷键

### 聊天输入

| 键位 | 操作 |
|---|---|
| `Enter` | 发送消息（如果行以 `!` 开头，则在 [bash 模式](#bash-mode) 下运行 shell 命令） |
| `Ctrl+Enter` / `Alt+Enter` / `Shift+Enter` | 插入换行符 |
| `Up` / `Down` | 移动光标，然后导航历史记录 |
| `Tab` | 自动补全命令或文件路径；在空输入时，接受 [下一次提示词建议](#next-prompt-suggestion) |
| `Shift+Tab` | 循环切换权限模式：`strict` → `auto` → `yolo`。立即生效，包括对已在运行的回合 |
| `Ctrl+R` | 在提示词历史中启动反向搜索 (reverse-i-search) |
| `Ctrl+C` | 中断活动的回合；连续按两次退出（或使用 `/exit`） |
| `Ctrl+S` | 将队列中的消息引导至正在运行的回合 |
| `Ctrl+V` | 从剪贴板粘贴文本或图片 |
| `Escape` | 关闭弹出窗口，或者在没有窗口打开时中断活动的回合 |

### 行编辑

输入框支持 readline 风格的编辑以及多步撤销/重做：

| 键位 | 操作 |
|---|---|
| `Ctrl+A` / `Home` | 跳转到行首 |
| `Ctrl+E` / `End` | 跳转到行尾 |
| `Alt+B` / `Ctrl+←` | 移动到上一个词 |
| `Alt+F` / `Ctrl+→` | 移动到下一个词 |
| `Ctrl+W` / `Alt+Backspace` | 删除上一个词 |
| `Alt+D` | 删除下一个词 |
| `Ctrl+D` | 删除光标下的字符 |
| `Ctrl+K` | 从光标处剪切（删除）至行尾 |
| `Ctrl+U` | 从行首剪切（删除）至光标处 |
| `Ctrl+Y` | 粘贴最近剪切的文本 |
| `Ctrl+Z` | 撤销上一次编辑 |
| `Alt+Z` | 重做 |

### 全局快捷键

| 键位 | 操作 |
|---|---|
| `Ctrl+T` | 打开主题对话框 |
| `Ctrl+P` | 在聊天输入框和嵌入式终端面板之间切换焦点（如果关闭则打开它；使用 `/pty` 关闭） |
| `Ctrl+E` | 停止正在运行的 llama 服务器（离线模式） |
| `Ctrl+O` | 切换本地推理日志面板 |
| `Ctrl+K` / `Ctrl+J` | 向上/向下滚动推理日志 |

### 差异视图（全屏）

| 键位 | 操作 |
|---|---|
| `j` / `Down` | 向下滚动 |
| `k` / `Up` | 向上滚动 |
| `Page Down` / `Page Up` | 翻页 |
| `Home` / `End` | 跳转到顶部/底部 |
| `q` / `Escape` | 关闭差异视图 |

### 工具审批

| 键位 | 操作 |
|---|---|
| `↑` / `↓` (或 `k` / `j`) | 在选项之间移动 |
| `1` / `2` / `3` / `4` | 直接选择 Yes / for-session / always-allow / No |
| `y` / `Enter` | 确认高亮选项 |
| `Esc` | 拒绝工具调用 |
| `Tab` | 预览差异或请求详情 |

### 反向搜索 (Ctrl+R 模式)

| 键位 | 操作 |
|---|---|
| `Ctrl+R` | 下一个匹配项 |
| `Ctrl+S` | 上一个匹配项 |
| `Enter` | 接受匹配项 |
| `Escape` / `Ctrl+G` | 取消搜索 |

## @ 提及

在输入框中键入 `@` 以引用文件或目录。键入时会出现文件搜索下拉菜单：

- `@path/to/file.rs` — 将文件内容嵌入到你的消息中
- `@path/to/dir/` — 嵌入目录树列表

:::tip
如果你粘贴多个文件路径，Ante 为了方便会自动为它们添加 `@` 前缀。
:::

## Bash 模式 {#bash-mode}

在任何输入前加上 `!` 前缀，即可直接将其作为 shell 命令运行，而不是发送给智能体：

```
!git status
!cargo build
```

该命令将在你自己的登录 shell（`$SHELL -lc`，回退为 `/bin/sh`）中从当前工作目录运行，超时时间为 120 秒。它的输出会显示在对话中，并作为下一个回合的上下文提供给智能体，因此你可以自己运行命令，然后要求智能体对打印的内容采取行动。

:::note
Bash 模式在本地运行，绝不受权限系统的门控——键入 `!` 即为授权。这独立于智能体自身的 `Bash` 工具（后者仍需经过工具审批）。后面不跟任何内容的单独 `!` 会作为普通消息发送。交互式程序（编辑器、分页器）无法工作，因为 bash 模式没有终端输入。
:::

## 下一次提示词建议 {#next-prompt-suggestion}

当一个回合结束且输入框为空时，Ante 会预测一个可能的后续提示，并将其显示为暗淡的幽灵文本。按 `Tab` 键接受它——该建议会填充到输入框中，以便你在发送前进行编辑。除 `Tab` 以外的任何击键都会忽略它。

此预测是在非关键路径上通过可用的最便宜模型生成的，因此它永远不会减慢你的回合速度，并且如果无法及时生成，它也会静默忽略，不执行任何操作。该功能默认开启；在 `~/.ante/settings.json` 中设置 `"ambient_prompt_suggestion": false` 即可关闭它。

## 加载思考短语 {#spinner-thinking-phrase}

当你键入较长的提示词时，Ante 会预测一个特定于任务的简短短语，并将其用作该回合的加载标签（spinner label），而不是通用的旋转消息。与下一次提示词建议一样，它在非关键路径上在最便宜的模型上尽力运行，并且会从短语中过滤掉令人担忧或具有破坏性的词语。默认开启；可以在 `~/.ante/settings.json` 中使用 `"ambient_thinking_phrase": false` 禁用它。

## TUI 模式的 CLI 标志

```bash
ante --model claude-sonnet-4-6
ante --provider openai
ante --system-prompt "You are a Python expert"
ante --append-system-prompt "Always use type hints"
ante --include-tools Read Grep Glob
ante --exclude-tools Bash Write
ante --yolo                       # 跳过所有工具审批
ante --resume ses_01ARZ3NDEK...   # 恢复之前的会话
```
