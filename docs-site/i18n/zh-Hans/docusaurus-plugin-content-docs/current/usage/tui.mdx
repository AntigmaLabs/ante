title: 交互式 TUI
description: "探索项目、修改代码、审查结果，并在之后继续工作"
---

在 TUI 中，你可以和 Ante 一起完成任务：提出问题、添加上下文、审查修改，并决定下一步。

在项目目录中打开终端并运行：

```bash
cd your-project
ante
```

首次使用时，请先[连接提供商](/usage/providers)，然后发送提示词。

## 探索不熟悉的项目 {#explore-an-unfamiliar-project}

先提出一个范围明确的问题：

```text
解释这个项目如何启动。找到主要入口，并追踪请求如何到达数据库。
```

输入消息并按 `Enter`。Ante 会流式显示回答，以及过程中使用的文件和命令。可以继续在同一对话中追问，缩小调查范围。

要指定某个文件，输入 `@` 并从补全菜单中选择：

```text
解释 @src/main.rs，并说明它依赖哪些模块。
```

也可以引用文件夹、粘贴截图或提供网址。相关流程请参阅[提供上下文](/usage/providing-context)。

## 修改代码并审查结果 {#make-a-change-and-review-it}

告诉 Ante 明确的目标和约束：

```text
配置文件缺失时，显示清晰的错误消息。保留现有 CLI 行为，并运行相关测试。
```

1. **明确任务。** Ante 提问时，可以选择选项，或使用 **Chat about this** 进一步解释需求。
2. **审查请求的操作。** 工具需要授权时，按 `Tab` 查看拟议的 diff 或命令详情。可以批准、拒绝，或拒绝并说明应如何调整。
3. **检查结果。** 当前轮次结束后，运行 `/diff` 查看工作区修改，包括未跟踪文件。需要调整时，继续告诉 Ante。
4. **验证目标。** 请 Ante 运行相关检查，并在结束前解释失败原因。

权限选项与会话授权请参阅[审批指南](/usage/approvals)。

### 回答澄清问题 {#answer-a-clarifying-question}

需要你的输入时，Ante 可以直接在 TUI 中显示带有选项的问题。阅读选项，使用方向键选择，再按 `Enter` 确认。若想自行输入答案或讨论这个决定，可以选择 **Type something** 或 **Chat about this**。

### 查看完整执行细节 {#transcript-view}

按 `Ctrl+O` 打开完整记录，包括主对话中折叠的工具输出和思考内容。使用 `j` / `k` 或 `PgUp` / `PgDn` 滚动，再按 `Ctrl+O` 或 `q` 返回对话。

## 在执行中调整方向 {#change-direction-while-ante-works}

如果需要补充约束，可以在 Ante 运行时输入并按 `Enter`：

```text
也处理空配置文件，并复用现有错误类型。
```

消息会进入队列。按 `Ctrl+S` 将指导立即送入当前轮次，或留在队列中等待下一轮执行。

要停止当前操作，可以在没有弹窗时按 `Escape`，或按 `Ctrl+C`。然后发送修正后的提示词；对话上下文仍然保留。示例请参阅[中断与引导](/usage/steering)。

## 撤回提示词 {#rewind-a-conversation}

运行 `/rewind`，或在输入框为空且无弹窗时快速按两次 `Esc`。选择器会按从新到旧的顺序列出仍可恢复的输入。用方向键选择，按 `Enter` 确认，或按 `Esc` 取消。

Ante 会将当前对话恢复到所选输入之前，移除该输入及其后的对话，并将提示词文字放回输入框供你修改。修改后按 `Enter` 才会开始新一轮。

回退只改变对话和模型上下文，**不会撤销文件编辑、Shell 命令或其他外部操作**。先等待或中断当前轮次，处理完排队输入，并用 `/goal clear` 清除目标；回退还需等待后台任务结束。必须启用会话保存。只能选择本次启动或恢复以来仍可恢复的输入；压缩或切换提供商后，之前的回退点不再可用。

## 分叉对话 {#fork-a-conversation}

运行 `/fork` 可保存一份独立对话并切换到它。选择 **(end of conversation)** 可保留完整对话；也可选择某条可恢复输入，从该输入之前创建分支，并将其提示词文字放回输入框。按 `Enter` 确认或 `Esc` 取消。

原会话保持不变。新会话标题下会显示来源会话 ID；使用 `/resume` 可返回原会话。分叉需要启用会话保存、没有运行或排队的轮次，且没有活动目标。选择输入时与回退共享相同的恢复边界；即使没有可恢复输入，也能分叉完整对话。分叉只保存并切换对话，不会创建 Git 分支或独立工作目录，也不会自动开始新任务。

若要让另一个智能体同时工作，请使用[另一终端中的会话](#branch-in-another-terminal)。

## 自己运行命令 {#bash-mode}

以 `!` 开头可直接执行 Shell 命令：

```text
!git status
!cargo test
```

命令输出会成为下一条消息的上下文。接着输入 `解释这次失败，并修复根本原因。`，即可让 Ante 根据刚才的结果继续工作。

这些命令会在你的授权下立即运行。交互式程序请使用终端会话。

## 使用 /term 编排智能体 {#terminal-sessions}

`/term` 打开一个你和 Ante 都能操作的终端。可以在其中运行另一个 Ante 实例、Claude Code、Codex、开发服务器或 REPL。你可以在主对话中下达指令，观看另一个程序工作，也可以随时直接输入并参与操作。

### 打开智能体并分配任务 {#open-an-agent-and-give-it-a-task}

安装 `tmux` 后，在 Ante 中输入：

```text
/term ante
```

新建的终端会话会在分屏或窗口中启动另一个 Ante 实例。回到主对话，可以这样说：

```text
在 ante 终端中，请另一个智能体审查当前 diff。
读取它的发现，并告诉我哪些问题需要处理。
```

Ante 会发送任务、读取另一个智能体的输出，并在你观看时继续追问。下面的演示展示了打开另一个 Ante 会话、提出问题、读取回答和分离查看窗口的过程：

</a>

使用 `/term claude` 或 `/term codex` 可打开对应的已安装 CLI。可以请 Ante 将同一问题交给多个智能体并比较答案，也可以让不同会话分别承担任务的一部分。每个终端保留自己的对话，你可以直接参与，回答问题或调整工作方向。

### 在另一终端中探索 {#branch-in-another-terminal}

若想从已保存的 Claude Code 或 Codex 对话中探索另一个方向，先打开一个新的命名终端：

```text
/term review
```

根据已安装的智能体，在该终端中选择运行以下一条命令：

```bash
# 分叉当前目录中最近的 Claude Code 对话
claude --continue --fork-session

# 分叉最近的 Codex 对话
codex fork --last
```

智能体自身的分叉命令会将已保存的对话带入新会话。若想与当前 Ante 对话并行开展工作，可以请 Ante 启动另一个命名会话，并明确交接上下文：

```text
启动另一个名为 edge-cases 的 Ante 会话。
把我们的任务、约束和当前发现交给它，让它调查边界情况，
同时我们继续在这里实现功能。
```

然后通过 `/term edge-cases` 查看或加入该对话。交接内容为新智能体提供上下文；各会话保留独立的历史记录。

### 管理持久交互式子智能体 {#keep-interactive-subagents-available}

运行 `/term` 列出当前会话并连接到需要的终端。再次运行 `/term <name>` 会分离查看窗口，程序仍继续运行。主 Ante 退出或重启后，终端会话依然保留；只要 tmux 服务仍在运行，后续对话就可以重新连接并继续协调它们。

打开已有会话会连接到正在运行的程序；启动参数只在创建会话时生效。需要另一个智能体或对话分支时，使用新的会话名称，并请 Ante 在其中启动程序。任务完成后，通过 `/term` 选择器停止会话。

开发服务器、REPL 和其他交互式工具也可以使用同样的流程。启动选项、支持的终端应用及会话管理请参阅[终端控制](/reference/tui-reference#terminal-sessions)；通过内置 `Agent` 工具委派任务请参阅[子智能体](/extend/subagents)。

## 为下一步选择模型 {#choose-a-model-for-the-next-step}

使用 `/models` 调整当前提供商的模型或思考深度。要切换提供商，使用 `/providers`，然后在选择器中确认模型。

例如，可以先用一个模型探索代码，再在同一对话中选择另一个模型解决困难的调试问题。选择流程请参阅[模型与思考深度](/usage/models-and-thinking)。

### 查看会话用量 {#session-usage}

运行 `/usage` 查看各模型的 Token 用量、缓存使用及轮次统计。受支持的订阅还会显示额度信息。这些数据帮助你了解当前会话；账单仍以提供商控制台为准。

## 继续较长的任务 {#continue-a-longer-task}

对于有明确完成条件的任务，可以设置目标：

```text
/goal 所有测试通过，且 cargo clippy 不报告警告
```

Ante 会持续检查进展是否满足条件。使用 `/goal` 查看状态，使用 `/goal clear` 结束循环。完成与中断规则请参阅[目标会话](/usage/goal-sessions)。

对话变长时，可运行 `/context` 查看上下文大小。使用 `/compact 重点保留尚未解决的测试失败` 总结较早的工作，并保留下一步需要的信息。

### 为任务命名 {#session-title}

离开前，为对话起一个容易识别的名字：

```text
/rename 配置错误处理
```

标题会显示在恢复选择器和终端标签页中。

### 从上次进度继续 {#session-resume}

启用会话保存时（默认开启），可以通过 `/exit` 退出并在之后恢复：

1. 在同一个项目目录中运行 `ante`。
2. 输入 `/resume`，按标题或首条消息找到对话。
3. 按 `Enter`，然后发送下一条指令。

<a href="/assets/cookbook/resume-demo-1.gif" target="_blank" rel="noreferrer">
  <img src="/assets/cookbook/resume-demo-1.gif" alt="使用 /resume 选择已保存的对话并发送新消息继续工作" className="cookbook-demo" loading="lazy" />
</a>

Ante 会恢复保存的对话，并使用当前权限设置。也可以运行 `ante --resume`（或 `ante -r`）直接打开选择器，或用 `ante --resume <SESSION_ID>` 按 ID 指定会话。若当前目录没有已保存的会话，不带 ID 的 `--resume` 会提示后退出。使用 `--no-session-save` 启动的会话无法恢复。

选择器按最近使用时间排序。在 TUI 内恢复会话时，会清空当前屏幕并显示所选会话的标题与历史。已保存的系统提示词及提示词模式会保留；当前启动参数中的提示词选项只作用于全新会话。如果本地日期、操作系统或 Shell 改变，Ante 会在下一轮用一条通知告知模型。

### 接续 Claude Code 或 Codex 的工作 {#coming-from-claude-code-or-codex}

使用 `/resume-claude` 或 `/resume-codex` 接续当前项目中最近的对话。这些内置技能会读取之前的记录，梳理任务与进度，并在继续之前与你确认下一步。添加会话 ID 可选择特定对话。

## 调整终端体验 {#make-the-terminal-comfortable}

运行 `/config` 调整偏好，或使用 `/theme` 选择主题。若终端丢失内联滚动记录，可以使用 `ante --fullscreen` 启动，或在 `/config` 中修改 **Render mode**。

具体命令和控制方式请参阅[斜杠命令](/usage/slash-commands)、[快捷键](/reference/tui-reference#keyboard-shortcuts)以及 [TUI 参考手册](/reference/tui-reference)。
