# 模型选择、提供商与思考深度

Ante 允许在会话进行中随时无缝切换模型、提供商和思考深度（Effort）—— 完全无需重启会话。两个弹窗面板各司其职：`/models` 用于在当前提供商内细化选择模型和思考深度，而 `/providers` 用于在不同的提供商之间切换。

<img src="/assets/cookbook/providers.gif" alt="在 /providers 中选择提供商及其凭据，并打开其访问视图" className="cookbook-demo" />

## 选择模型 {#selecting-a-model}

在 TUI 终端中输入 `/models` 即可打开模型选择器面板。面板会列出当前提供商支持的模型（标题展示作用域，如 *Switch Model — Anthropic*）。使用方向键浏览模型，调节下方思考深度滑块，按 Enter 回车确认。

输入 `/models <model_id>` 可直接切换到当前提供商的指定模型。例如，在 Antix 上使用 Fable 5.2 时，先在 `/providers` 中选择 Antix。若您的端点已支持该模型，但本机选择器尚未列出，可将 Antix 提供的模型 ID 传给 `/models`。

在同一提供商内切换模型时（例如在 Antix 上从 Gemini 切换到 Claude），您可以继续当前对话。Ante 会在新模型的请求中清除旧模型专用的推理数据与工具调用签名。

在选择器中按 `Tab` 键可直接跳转至提供商选择面板。

## 切换提供商 {#switching-providers}

打开 `/providers`，选中已连接的提供商，然后按 `Enter` 选择模型。再按一次 `Enter` 确认，或按 `Esc` 返回。如果您有多个账户，可先用 `←` 和 `→` 选择本次会话使用的账户。

切换后可以继续当前对话。您发送的下一条消息会交给新提供商处理。首次使用某个提供商时，请先[登录或添加密钥](/usage/providers#authentication)。

## 思考深度 {#effort}

如果要梳理一个棘手问题，例如找出偶发测试失败的原因，可以在 `/models` 中提高思考深度。选中模型，调节模型列表下方的滑块，然后按 `Enter`。滑块只显示该模型支持的档位。如果模型不支持调节，界面会隐藏滑块。

Ante 会记住每个模型的选择。也可以仅为一次运行指定档位：

```bash
ante --effort high -p "分析这个间歇性失败的测试，找出可能的原因。"
```

`min` 选择该模型支持的最低档位。有些模型在这一档仍会推理。

## 查看推理摘要 {#readable-reasoning}

在聊天中按 `Ctrl+O` 打开会话记录，查看模型返回的推理内容。可见内容的多少取决于提供商。若要更改请求的摘要详细程度，请参阅[推理显示设置](/reference/catalog-reference#thinking-display)。
