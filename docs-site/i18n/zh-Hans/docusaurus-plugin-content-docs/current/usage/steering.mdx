# 中断与实时引导

无需等待智能体在错误的方向上完成整轮执行。Ante 支持在执行过程中随时中断并重新定向。

## 中断执行 {#interrupting}

按 `Ctrl+C` 可中断当前轮次。没有弹窗时，也可以按 `Escape`。

如果模型还没有输出文字、开始推理或调用工具，Ante 会将提示词放回输入框，随后依次放入本轮已发送的引导文字和仍在排队的消息。您可以编辑后按 `Enter` 重新发送。如需再次发送粘贴的图片，请重新附上图片。

Ante 会从对话末尾移除撤回的提示词。如果这些行已经进入终端的滚动历史，或后面还有其他命令，Ante 会保留这些行并显示 `Returned to input`。启用会话保存且没有后台任务时，Ante 还会回退模型上下文中的这轮输入；否则，模型仍可能看到原来的提示词。

如果模型已经输出文字、开始推理或调用工具，中断会保留此前的对话内容。发送后续消息即可调整方向。

## 不中断执行的实时引导 {#steering-without-interrupting}

您无需强行停止当前轮次也可以调整其方向。在智能体工作期间键入消息并按 `Enter` —— 消息不会发起新轮次，而是处于**排队（queued）**状态。随后：

- 按 `Ctrl+S` 进行**实时引导（steer）**：将排队的消息即时注入正在运行的轮次中作为实时指引，且不会打断当前执行。
- 如果让当前轮次正常结束，排队的消息会自动发起下一轮。

<img src="/assets/cookbook/steering.gif" alt="通过排队指引实时引导正在运行的 Ante 轮次" className="cookbook-demo" />

实时引导可以在不破坏智能体执行连贯性的同时微调方向，特别适合在思路正确但遗漏细节时（如“顺便更新对应的测试”、“复用现有的 helper 函数”）提供补充。

切换为新会话或恢复其他会话时，仍在队列中的消息会返回输入框，供您检查后重新提交。

## 历史提示词 {#command-history}

在输入区按键盘 `Up`（向上方向键）可以循环浏览之前的提示词，便于在中断后快速重新发送或微调。

:::tip
还可以按 `Ctrl+R` 使用反向增量搜索（reverse-i-search）检索完整的提示词历史 —— 便于查找会话早期的输入。
:::
