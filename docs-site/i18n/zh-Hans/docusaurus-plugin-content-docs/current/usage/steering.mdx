# 中断与引导 {#interrupting--steering}

不要等到智能体在错误的道路上走完才干预。Ante 允许您在任何时候中断并重定向它。

## 中断 {#interrupting}

在智能体生成内容时按 `Ctrl+C` 立即停止当前轮次（turn）。当没有打开的弹出窗口时，按 `Escape` 键也可以中断。智能体会保留到那一点为止的所有上下文，因此您可以通过后续消息进行纠偏 —— 无需从头开始。

这既节省了时间又节省了 token，特别是当您在早期就发现智能体正朝着错误的方向前进时。

## 不中断地引导 {#steering-without-interrupting}

您不必为了重定向而停止轮次。在智能体工作时键入消息并按 `Enter` 键 —— 它不会开始新的轮次，而是被**排队（queued）**。然后：

- 按 `Ctrl+S` 进行**引导（steer）**：将排队的消息刷新到正在运行的轮次中作为实时指导，而不会中断它。
- 或者什么也不做 —— 当前轮次结束后，排队的消息会自动提交。

引导保持了智能体的势头，同时轻推它改变方向，当智能体在正确的轨道上但缺少某个细节（“也更新测试”、“使用现有的辅助函数”）时，这是理想的选择。

## 命令历史 {#command-history}

在输入区域按 `Up` 向上箭头键，循环浏览您之前的提示词。这使得在中断后轻松地重新发送或调整最近的消息。

:::tip
您还可以使用 `Ctrl+R` 通过反向增量搜索（reverse-i-search）来搜索您的完整提示词历史记录 —— 当您想要查找会话早期的内容时，这非常方便。
:::
