# 斜杠命令（Slash Commands）

在[交互式 TUI 终端](/usage/tui)中输入 `/` 即可快速触发用于常见操作的内置斜杠命令：

| 命令 | 说明 |
|---|---|
| `/clear` | 清空当前对话历史 |
| `/init` | 自动分析当前项目并生成 `AGENTS.md` 智能体指引规范 |
| `/exit` | 退出 Ante |
| `/compact` | 压缩与总结历史对话，释放上下文窗口空间 |
| `/config` | 打开设置对话面板 —— 搜索、开关并跳转至主题、模型、提供商、状态栏、MCP 和离线设置（详见[偏好配置](/configuration/preference#settings-file)） |
| `/theme` | 打开主题切换弹窗 |
| `/diff` | 查看 Git 改动 Diff（包含未跟踪的新增文件） |
| `/connect` | 通过 OAuth 登录授权（API 密钥会自动检测） |
| `/models [model_id]` | 不带参数时打开当前提供商的模型与思考深度选择器；带参数时直接切换至指定模型（包括目录未列出的模型 ID） |
| `/providers` | 查看并切换当前会话生效的模型提供商 |
| `/offline-mode` | 通过内置推理引擎运行本地 GGUF 模型 |
| `/term [name [args...]]` | 不带参数时打开终端会话选择器；带名称时附加/分离对应的 tmux 会话（新会话时自动拉起同名命令）—— 详见[终端会话管理](/usage/tui#terminal-sessions) |
| `/update [skip \| cancel]` | 安排在退出时自动安装待更新的版本；`skip` 永久忽略该版本，`cancel` 取消计划安装 |
| `/context` | 以彩色色块网格形式可视化当前上下文 Token 占用分布（按类别分解） |
| `/usage` | 查看当前会话累计的 Token 消耗、各模型调用量、缓存命中率与 Turn 轮次统计（详见[会话消耗统计](/usage/tui#session-usage)） |
| `/welcome` | 重新打开欢迎与引导配置弹窗 |
| `/resume` | 恢复当前工作目录中此前保存的历史会话 |
| `/resume-claude [id]` | 在当前目录中继续接管最近的 Claude Code 会话（内置 Skill —— 详见[从 Claude Code 或 Codex 迁移](/usage/tui#coming-from-claude-code-or-codex)） |
| `/resume-codex [id]` | 在当前目录中接管最近的 Codex 会话（内置 Skill） |
| `/skill-creator` | 创建、改进与评测自定义 [Skills 技能](/extend/skills)（内置 Skill） |
| `/import-claude` | 将当前目录下的 Claude Code 项目记忆导入至 Ante 的[项目记忆库](/extend/memory#importing-claude-code-memory) |
| `/statusline` | 配置与自定义底部状态栏项 |
| `/mcp` | 检查并管理已配置的 [MCP 服务器](/extend/mcp) |
| `/goal [<condition> \| clear]` | 开启目标导向会话直至满足验收条件，或清除当前目标/查看状态 |

:::note
部分命令是“可见”命令（操作记录会保留在对话流中），另一些则是“静默”命令（执行后不计入对话流）。其中 `/clear`、`/init`、`/exit`、`/compact`、`/context`、`/usage` 和 `/goal` 会在对话历史中留痕；其余命令均为静默执行。
:::

## Skills 技能作为斜杠命令

配置的 [Skills 技能](/extend/skills) 也会自动作为斜杠命令出现在菜单中，并带有作用域标记：`[p]` 代表项目级技能（Project），`[u]` 代表用户级全局技能（User），`[s]` 代表内置系统技能（System）。

在输入时，匹配已知命令或技能的词条会在输入框中高亮显示，方便在发送前即时确认。

## 相关章节
