# 斜杠命令 {#slash-commands}

在[交互式 TUI](/usage/tui)中输入 `/` 即可运行内置命令来执行常见操作：

| 命令 | 描述 |
|---|---|
| `/clear` | 清除对话历史记录 |
| `/init` | 分析项目并创建 `AGENTS.md` 文件 |
| `/exit` | 退出 Ante |
| `/compact` | 总结对话历史以释放上下文窗口空间 |
| `/theme` | 打开主题选择对话框 |
| `/diff` | 显示 git diff（包括未跟踪的文件） |
| `/connect` | 使用 OAuth 登录（会自动检测 API 密钥） |
| `/model` | 选择一个模型和已连接的提供商 |
| `/providers` | 为当前会话选择一个可用的提供商 |
| `/offline-mode` | 使用内置推理引擎运行本地模型 |
| `/pty` | 切换嵌入的终端面板（使用 `Ctrl+P` 切换焦点） |
| `/welcome` | 显示欢迎/引导对话框 |
| `/resume` | 恢复此目录中之前的会话 |
| `/statusline` | 配置状态栏 |
| `/mcp` | 检查和管理已配置的 [MCP 服务器](/extend/mcp) |
| `/goal [<condition> \| clear]` | 持续工作直到满足条件，清除活动目标，或显示目标状态 |

:::note
有些命令是“可见的”（出现在对话历史记录中），而另一些是“静默的”（执行时不添加到历史记录中）。`/clear`、`/init`、`/exit` 和 `/compact` 是可见的；其余的是静默的。
:::

## 作为斜杠命令的技能 {#skills-as-slash-commands}

[技能（Skills）](/extend/skills)也表现为斜杠命令，并带有作用域指示符：`[p]` 表示项目级，`[u]` 表示用户级，`[s]` 表示系统级技能。

## 相关内容 {#related}

- `/goal` 驱动[目标驱动的会话](/usage/goal-sessions)：持续工作，直到满足成功条件。
- `/resume` 重新拾起以前的对话；参见[会话恢复](/usage/tui#session-resume)。
