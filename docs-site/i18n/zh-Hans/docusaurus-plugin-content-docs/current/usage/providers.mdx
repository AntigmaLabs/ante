---
title: 连接提供商
description: "通过 TUI 或 CLI 登录，或使用提供商 API 密钥"
---

为 Ante 连接提供商，选择模型，然后开始对话。可以使用受支持账户在浏览器中登录，也可以提供自己的 API 密钥。

## 在 TUI 中登录 {#authentication}

1. 在项目目录中运行 `ante`。
2. 输入 `/providers`，选中 **Antix**、**Anthropic Subscription** 或 **OpenAI Subscription**，按 `m` 管理其访问方式（尚未设置的提供商也可直接按 `Enter`）。
3. 选择 **Sign in to …**（例如 **Sign in to Antix**），按提示在浏览器中完成登录，然后返回 Ante。
4. 登录成功后，Ante 会在对话中显示提供商名称，以及提供商返回的账户信息。按 `Enter` 继续。如果会话已在使用其他提供商，打开 `/providers` 即可切换。

<img src="/assets/cookbook/providers.gif" alt="在 /providers 中选择提供商及其凭据" className="cookbook-demo" />

Ante 会保存凭据供后续会话使用。需要重新登录时，打开 `/providers` 并再次按 `m`。

## 在 CLI 中登录 {#sign-in-from-the-cli}

可以在启动 TUI 或执行无头任务之前完成登录：

```bash
ante auth login antix        # or anthropic, openai
ante --provider antix
```

第一条命令会打开浏览器。完成登录后，回到终端执行第二条命令。在远程机器上，添加 `--no-browser` 可改为打印登录 URL。

如需添加第二个账户，请为其指定标签：`ante auth login anthropic/work`。`ante auth list` 会列出已保存的凭据。全部命令请参阅 [`ante auth`](/reference/cli-reference#ante-auth)。

## 使用 API 密钥 {#use-an-api-key}

在运行 Ante 的 Shell 中导出提供商的 API 密钥，然后选择对应提供商：

```bash
export ANTHROPIC_API_KEY="your-api-key"
ante --provider anthropic
```

如果想保存密钥而不是每次导出，运行 `ante auth add <provider>` 并粘贴密钥：

```bash
ante auth add anthropic
```

### 在 TUI 中粘贴密钥 {#paste-an-api-key}

输入 `/providers`，选中提供商，按 `m`，然后选择 **Add or replace API key**（添加或替换 API 密钥）。Ante 会向提供商验证密钥，然后将其保存到 `~/.ante/auth/`，仅允许当前用户访问。对于内置提供商，环境变量中的密钥优先于已保存的密钥。在同一视图中也可以删除已保存的密钥。

## 选择模型并开始工作 {#selecting-a-provider}

在 `/providers` 中选择已连接的提供商并确认模型。如果保存了多个账户，可先用 `←` 或 `→` 选择本次会话要使用的账户。

在输入框中提问，例如“项目在哪里处理配置文件缺失的情况？” 然后按 `Enter`。您可以继续[检查代码并审阅修改](/usage/tui)，也可以在会话中用 `/models` 切换模型。

## 自定义端点与本地模型 {#custom-endpoints-and-local-models}

如需连接自己的模型端点，运行 `/add-provider` 并按提示输入端点信息，重启 Ante 后，在 `/providers` 中选择它。手动配置方法见[自定义提供商](/reference/catalog-reference#custom-catalog)。

若要在自己的硬件上运行模型且无需凭据，请参阅[离线模式](/local/offline)。
