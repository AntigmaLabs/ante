---
title: 连接提供商
description: "通过 TUI 或 CLI 登录，或使用提供商 API 密钥"
---

为 Ante 连接提供商，选择模型，然后开始对话。可以使用受支持账户在浏览器中登录，也可以提供自己的 API 密钥。

## 在 TUI 中登录 {#authentication}

1. 在项目目录中运行 `ante`。
2. 输入 `/connect`，选择 **Antix**、**Anthropic Subscription** 或 **OpenAI Subscription**。
3. 按提示在浏览器中完成登录，然后返回 Ante。
4. 打开 `/providers`，选择已连接的提供商并确认模型。

<img src="/assets/cookbook/connect.gif" alt="通过 /connect 接入提供商" className="cookbook-demo" />

Ante 会保存凭据供后续会话使用。需要重新登录时，再次运行 `/connect`。

## 在 CLI 中登录 {#sign-in-from-the-cli}

使用 Antix 时，可以在启动 TUI 或执行无头任务之前完成 OAuth 登录：

```bash
ante auth login antix
ante --provider antix
```

第一条命令会打开浏览器。完成登录后，回到终端执行第二条命令。

CLI 登录目前支持 Antix。Anthropic 和 OpenAI 订阅请通过 TUI 中的 `/connect` 登录。`--no-browser` 和 `--force` 选项请参阅 [`ante auth`](/reference/cli-reference#ante-auth)。

## 使用 API 密钥 {#use-an-api-key}

在运行 Ante 的 Shell 中导出提供商的 API 密钥，然后选择对应提供商：

```bash
export ANTHROPIC_API_KEY="your-api-key"
ante --provider anthropic
```

任何配置为从环境变量读取密钥的提供商都可以使用同样的流程。例如，`OPENAI_API_KEY` 对应 `--provider openai`，`ANTIX_API_KEY` 对应 `--provider antix-api-key`。完整名称和变量请查阅[目录参考手册](/reference/catalog-reference#built-in-providers)。

### 在 TUI 中粘贴密钥 {#paste-an-api-key}

运行 `/welcome` 并选择 **Use API key**。Ante 根据密钥前缀识别提供商，隐藏输入并验证密钥，然后将其保存到 `~/.ante/auth/`，仅允许当前用户访问。环境变量中的密钥优先于已保存的密钥。

在 API 密钥步骤中选择 Anthropic 后，可按 `Tab` 在浏览器中登录 Anthropic Console 并自动创建密钥。

## 选择模型并开始工作 {#selecting-a-provider}

输入 `/providers` 选择已连接的提供商，然后确认模型和思考深度。Ante 会记住每个提供商上次使用的模型。在对话中使用 `/models` 可切换当前提供商的模型。

也可以在启动 Ante 时指定提供商和模型：

```bash
ante --provider antix --model claude-sonnet-5-5
```

接下来可以[在 TUI 中完成一个任务](/usage/tui)。模型选择与切换请参阅[模型与思考深度](/usage/models-and-thinking)。

## 自定义端点与本地模型 {#custom-endpoints-and-local-models}

对于非内置的托管端点或本地服务，可以在 TUI 中运行 `/add-provider`，或按[自定义模型目录范例](/reference/catalog-reference#custom-catalog)配置。[目录参考手册](/reference/catalog-reference)包含提供商列表、模型参数与配置示例。

若要在自己的硬件上运行模型且无需凭据，请参阅[离线模式](/local/offline)。
