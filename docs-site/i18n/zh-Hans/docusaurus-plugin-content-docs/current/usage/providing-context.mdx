# 提供上下文：文件、文件夹与 Web {#providing-context-files-folders--the-web}

为智能体提供它所需的确切上下文：在您的提示词中直接引用本地文件和目录，或者让 Ante 从网络上获取它所需的内容。

## 使用 @ 提及 {#using--mentions}

输入 `@` 后跟文件或目录路径。Ante 会在您键入时显示一个搜索下拉列表 —— 按 Tab 键自动补全，然后按 Enter 键确认。

<img src="/assets/cookbook/files.gif" alt="Adding file context with @ mentions" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

- **`@path/to/file.rs`** —— 将完整的文件内容嵌入到您的消息中
- **`@path/to/dir/`** —— 嵌入目录树列表

这确保了智能体确切地看到了您正在询问的代码，而无需猜测或搜索。

:::tip
如果您粘贴了多个文件路径，Ante 为了方便会自动在它们前面加上 `@` 前缀。您可以在单个提示词中引用任意数量的文件。
:::

## 提取网络内容 {#pulling-in-web-content}

Ante 可以搜索网络并从 URL 提取内容，让您无需离开终端即可引入文档、查找 API 或研究主题。只需自然地提问，Ante 就会使用其网络浏览工具来找到您需要的内容：

<img src="/assets/cookbook/webbrowse.gif" alt="Ante performing a web search" style={{width: '100%', borderRadius: '8px', margin: '16px 0'}} />

智能体可以：

- **搜索网络**以获取文档、示例和答案
- **提取 URL**以直接读取其内容（例如，API 文档、发行说明、博客文章）
- **总结**结果并将它们整合到对话中

当您使用不熟悉的库，或者需要检查某个工具或 API 的最新文档时，这特别有用。

:::note
提取 URL（`WebFetch`）默认开启。完整的网络**搜索**（`WebSearch`）通过提供商的原生搜索运行，因此它仅在支持它的提供商（Anthropic、OpenAI、Gemini、Grok、OpenRouter、Antix 或 Ali Coding Plan）上可用。在这些提供商上，它会自动启用 —— 无需标志；在其他提供商上则不提供。参见[工具参考](/reference/tools-reference#websearch)。
:::

:::tip
您也可以从命令行通过管道将网络内容传入 Ante：`curl https://example.com/docs | ante -p "summarize this"`。
:::
