# 通信协议参考手册（Protocol Reference）

Ante 在客户端（Client）与守护进程（Daemon）之间采用强类型消息传递协议。进程内采用 Tokio 异步有界通道通信；外部客户端通过基于 stdin/stdout 的 **JSON Lines (JSONL)** 格式交互。

## 报文通信格式（Wire Format）

外部客户端通过标准输入输出按行发送与接收 JSON 对象：

- **Client → Daemon**：向 stdin 写入 `OpMsg` 操作指令 JSON 行
- **Daemon → Client**：从 stdout 读取 `EventMsg` 状态事件 JSON 行

### `OpMsg` 信封格式

每个操作指令均包装在 `OpMsg` 中：

```json
{
  "op": { "StartSession": { "model": "claude-sonnet-5", "provider": "anthropic" } },
  "id": "op_01ARZ3NDEKTSV4RRFFQ69G5FAV"
}
```

### `EventMsg` 信封格式

每个状态事件均包装在 `EventMsg` 中：

```json
{
  "timestamp": "2025-06-01T12:00:00Z",
  "id": "evt_01ARZ3NDEKTSV4RRFFQ69G5FAV",
  "event": { "AgentMessage": "这是生成的代码..." },
  "parent": "op_01ARZ3NDEKTSV4RRFFQ69G5FAV"
}
```

`parent` 字段回溯触发该事件的操作指令 ID。

## 消息 ID 规范

每个 ID 均由前缀加 [ULID](https://github.com/ulid/spec) 组成（`{prefix}_{ulid}`）：

| 前缀 | 用途 |
|---|---|
| `op_` | 操作指令（Client → Daemon） |
| `evt_` | 状态事件（Daemon → Client） |
| `ses_` | 会话全局唯一标识 |
| `step_` | 模型单步调用标识 |

## 操作指令列表（Ops）

### StartSession（启动会话）

使用指定的模型、提供商和权限配置初始化新会话：

```json
{
  "op": {
    "StartSession": {
      "model": "claude-sonnet-5",
      "provider": "anthropic",
      "permission_mode": null,
      "system_prompt": null,
      "append_system_prompt": null,
      "tools": null,
      "include_tools": null,
      "exclude_tools": null,
      "cwd": null,
      "effort": null,
      "enable_auto_memory": null,
      "short_prompt": null,
      "no_skills": null
    }
  },
  "id": "op_..."
}
```

### UserInput（用户输入提示词）

```json
{
  "op": {
    "UserInput": "请解释这段代码"
  },
  "id": "op_..."
}
```

### Steer（实时引导）

向当前正在执行的轮次注入补充指导：

```json
{
  "op": {
    "Steer": "同时补充测试用例"
  },
  "id": "op_..."
}
```

### ApprovalResponse（工具调用审批）

```json
{
  "op": {
    "ApprovalResponse": {
      "turn_id": "turn_...",
      "responses": [
        { "Accept": null }
      ]
    }
  },
  "id": "op_..."
}
```

拒绝时可附带明确理由：

```json
{
  "op": {
    "ApprovalResponse": {
      "turn_id": "turn_...",
      "responses": [
        { "Deny": { "message": "请改用只读方式查询" } }
      ]
    }
  },
  "id": "op_..."
}
```

### Shutdown（退出守护进程）

```json
{
  "op": "Shutdown",
  "id": "op_..."
}
```

## 事件流列表（Events）

- `SessionStart` / `SessionEnd`：会话开始与结束
- `TurnStart` / `TurnPause` / `TurnEnd`：轮次生命周期（`TurnPause` 触发审批等待）
- `ThinkingDelta` / `Thinking`：增量与完整思考流
- `MessageDelta` / `AgentMessage`：增量与完整回复文本
- `ToolStart` / `ToolUpdate` / `ToolEnd`：工具执行生命周期
- `UsageUpdate`：Token 消耗与统计
- `CompactStart` / `CompactEnd`：上下文自动压缩状态
- `ExtensionRefreshed`：Skills 与子智能体变更通知
