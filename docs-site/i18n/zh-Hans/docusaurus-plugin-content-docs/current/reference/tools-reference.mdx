---
title: "Tools 参考"
description: "在 Ante 会话期间可用的工具参考"
---

工具 (Tools) 是 Agent 在会话期间可用的能力。有些工具会在后台静默运行；另一些则需要在执行前获得您的批准，除非有权限规则允许自动执行。

## 文件输入输出 (File I/O)

### Read

读取文本文件、图像和 PDF。当活跃模型没有视觉支持时，读取图像会返回其元数据（类型和尺寸）而不是图像本身，以便 Agent 知道文件存在并可以通过程序进行检查。

### Write

创建或覆盖文件。需要审批。

### Edit

在文件中进行精确的字符串替换。需要审批。

### Glob

按 Glob 模式查找文件。

### Grep

使用正则表达式搜索文件内容。

## Shell

### Bash

执行 Shell 命令。每次调用都在一个新的非交互式进程中运行 —— Shell 状态不会在调用之间持久保留。长时间运行的命令（服务器、监听器、耗时的构建）可以在后台启动；Agent 会返回可以读取以获取状态和输出的路径，并可以通过其 PID 停止进程。后台命令末尾的 `&` 是多余的，会自动被剥离。需要审批。

## 内置工具 (Builtin)

### Agent

派生一个子代理 (sub-agent) 来自主处理任务。Agent 会根据任务选择委派给哪个子代理。

### TodoWrite

通过任务列表跟踪多步工作的进度。

### WebFetch

获取一个 URL 的内容，将其转换为 Markdown，并使用小型模型提取相关信息。需要审批。

### WebSearch

搜索 Web 并返回带有引用的结果。需要审批。使用提供商的原生 Web 搜索，因此它仅在声明 `supports_web_search`（Anthropic、OpenAI、Gemini、Grok、OpenRouter、Antix 和 Ali Coding Plan）的提供商上可用。在这些提供商上，它会自动添加到工具集中；在其他提供商上则不提供。

## 可选工具 (Opt-in tools)

这些工具默认未启用。使用 `--include-tools` 开启它们。

### ViewImage

读取图像并根据自然语言指令进行分析。

### PTY

驱动持久的共享 tmux 会话 —— 适用于需要在多次调用间保持状态的交互式程序和全屏 TUI 应用程序。需要 `tmux`。

### Browser

驱动 Chromium 浏览器进行导航、内容提取和自动化。Agent 通常会截取页面快照以查找交互式元素，然后点击或输入。需要审批，且仅在构建 Ante 时启用 `browser` Cargo 功能特性时才可用。

## MCP 工具

配置的 [MCP 服务器](/extend/mcp) 提供的工具会以 `mcp__<server>__<tool>` 的形式暴露给 Agent。它们与内置工具一起显示，且从 Agent 的视角来看行为完全相同。MCP 工具遵守与内置工具相同的 `--include-tools`/`--exclude-tools` 过滤规则，因此如果限制性的包含列表没有列出它们，就会将它们移除；如果要针对每个服务器进行过滤，请改为使用 `enabled_tools`。

## 默认工具集 (Default tool set)

默认情况下，Ante 启用 `Read`、`Bash`、`Grep`、`Glob`、`TodoWrite`、`WebFetch`、`Edit`、`Write` 和 `Agent`。当 Ante 使用 `browser` 特性构建时，还会包含 `Browser`。当会话的提供商支持原生 Web 搜索时，会自动添加 `WebSearch`。

`ViewImage` 和 `PTY` 是可选的 (opt-in)。

## 工具过滤 (Tool filtering)

控制在会话中可用的工具：

```bash
# 仅允许这些工具
ante --include-tools Read Glob Grep "分析代码"

# 移除这些工具
ante --exclude-tools Bash Write "只读分析"
```

支持 ToolMatcher 语法以进行细粒度控制：

```bash
# 允许 Bash，但仅针对特定模式
ante --include-tools "Read" "Bash(cargo test)" "Bash(cargo clippy)"
```
