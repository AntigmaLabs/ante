# Ante {#ante}

**你的 shell 中的幽灵。** Ante 是一个存在于终端中的自包含且自组织的编程智能体。来自 [Antigma Labs](https://antigma.ai) 的一个仅约 15MB 的 Rust 二进制文件，零运行时依赖，旨在发挥任何模型的最大潜能。

它的工作方式类似于 Claude Code 或 Codex，但没有任何它们的依赖限制或模型约束。它还可以作为[构建您自己的应用](/usage/serve)和高性能助手的优化核心。

每个智能体都声称自己很优秀。这里有一些你可以验证的数据：

  <Card title="公开验证" icon="chart-line" href="https://antigma.ai/eval">

  </Card>
  <Card title="原生离线" icon="wifi-slash" href="/local/overview">

这三者源于同一个设计决策。一个可验证、负担得起、并且可以在任何地方运行的智能体，必须轻巧到可以*成千上万*个一起运行：这是自组织智能的基础。参见[理念](/start/philosophy)。

### 不仅仅是亮眼的数据 {#beyond-the-headline-numbers}

- **零供应商锁定。** 携带您自己的 API 密钥、订阅或本地模型。在 12+ 提供商之间自由切换 —— Anthropic、OpenAI、Gemini、Grok、Open Router 等。无需账户，没有遥测门槛，没有封闭花园。甚至我们自己也没有。
- **[多智能体编排](/experimental/agent-org)。** 协调多个智能体，围绕复杂任务进行自组织。
- **可扩展。** 自定义跨会话的[技能](/extend/skills)、[子智能体](/extend/subagents)、[MCP](/extend/mcp) 和持久化[记忆](/extend/memory)。
- **对简洁性和质量的坚持。** 在一个供给充足的世界里，保持质量和高水平的信任比以往任何时候都更有价值。

### 它是如何工作的 {#how-it-works}

Ante 采用客户端-守护进程架构运行。守护进程管理结构化的轮次生命周期 —— 提示词（prompt）、工具调用、确认、执行 —— 通过一个安全、可预测的循环引导模型的能力。客户端可以是交互式的 TUI、无头的 CLI、外部进程，或者是通过 `ante gateway` 运行的频道机器人。

在架构上，Ante 正在向一个以智能体为中心的运行时演进，其中长期存在的智能体通过消息传递进行协调 —— 这是一种具有层次化监督、隔离状态和每个智能体清晰资源所有权的 Actor 模型。

Ante 也可以作为一个长生命周期的服务器（`ante serve`）运行，外部客户端通过结构化的 JSONL 协议驱动它 —— 非常适合构建编辑器插件、Web UI 和自定义集成。

:::warning
Ante 目前处于**预览版（preview）**并正在积极开发中。预计会出现破坏性更改、实验性功能以及不完整的功能。目前仅支持 **macOS** 和 **Linux**。
:::
