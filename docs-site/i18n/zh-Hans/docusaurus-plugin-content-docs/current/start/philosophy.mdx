# 设计哲学

Ante 专为**细胞原生 (Cellular-native)** 的智能体而设计 —— 这些智能体旨在实现大规模并行运行，而非孤立存在。我们所做的一切都服务于这一理念。

## 细胞原生 (Cellular-native)

如同生物体中的细胞 —— 微小、可消耗、大规模复制 —— 智能体应该足够轻量，以便成千上万地运行；并且足够可靠，当其中任何一个失败时，系统能够自我修复。这基于三大支柱：

- **轻量。** 我们要运行成百上千个智能体副本。每一个都不能占用数 GB 的内存 —— 尤其是在内存昂贵的当下。在大规模运行时，每个实例的每一字节都至关重要。这就是我们保持内核紧凑微小的原因：每一行代码都是一种负担。

- **可靠。** 多年分布式系统的经验告诉我们：可靠性带来的回报是非线性的。低于某个阈值，系统完全不可用；一旦越过该阈值，游戏规则就会改变。这里存在一个相变（Phase transition） —— 你必须站在正确的一侧。

- **闭环控制。** 智能体的管理与编排应当是直观且自我修复的 —— 自动收敛到期望状态。就像生物学中的稳态，基础设施中的 Kubernetes。声明式意图，自动化调节。个体智能体是可消耗的，而整个系统会持续运转。

## 工程原则

这些原则服务于“细胞原生”的理念：

- **文档是新的源代码。** 在 AI 原生的工作流中，规范和文档是持久的产物 —— 代码只是意图的下游副产物。我们优先编写文档并保持其权威性，让工程师和智能体都基于同一个事实来源进行工作。

- **用证据说话，拒绝空头承诺。** 每一个核心功能声明都附带一个针对用户实际安装版本的公开、可复现的基准测试：锁定的版本、可审计的运行记录以及[实时测试结果](https://antigma.ai/eval)。如果我们无法衡量，我们就不会宣称。

- **紧凑微小的内核。** 每一行代码都是一种负担。较小的内核意味着易于审计、编译迅速、便于推理 —— 且轻量到足以支持大规模复制。

- **最小化认知负担。** 更少需要学习的概念，更少需要调整的配置。如果一个功能需要一大段文字来解释，那它可能设计得太复杂了。

- **最小化依赖。** 依赖越少，意味着供应链风险越低、构建速度越快，受上游变更影响的概率越小。我们宁可引入（Vendor）或重写代码，也不轻易添加新的依赖库。

- **避免供应商锁定（包括我们自己）。** 你无需注册账号或登录即可使用 Ante。自带 API 密钥，自由切换模型提供商，或者使用本地模型完全离线运行。

- **原则性的智能体组织。** 智能体应该是有结构组织的，而不是自由散漫的。Ante 强制执行清晰的轮次生命周期和权限模型，以确保智能体行为具备可预测性和透明度。

- **在训练与推理之间形成闭环。** 评测（Evaluation）绝不是事后补充 —— 它是我们判断智能体脚手架是否优秀的标准。我们持续针对现实世界的任务进行基准测试，并将结果反馈到开发中。

- **精选与主见。** 我们拒绝盲从炒作与噪音，并坚定地在已形成行业共识的领域加倍投入。
