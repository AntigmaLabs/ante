# 理念 {#philosophy}

Ante 专为**云原生细胞化（cellular-native）**智能体而设计 —— 这些智能体为规模化运行而构建，而非孤立存在。我们所做的一切都是为了服务于这一论断。

## 云原生细胞化 {#cellular-native}

就像生物体中的细胞一样 —— 微小、可消耗、大规模复制 —— 智能体应该足够轻量，以便成千上万地运行；同时也应该足够可靠，当其中任何一个失败时，系统能够自我修复。三大支柱：

- **轻量。** 我们运行着成百上千的智能体副本。每一个不能占用几GB的内存 —— 尤其是现在，当RAM非常昂贵时。在规模化的情况下，每个实例的每个字节都很重要。这就是为什么我们保持一个紧凑、微小的核心：每一行代码都是一种负担。

- **可靠。** 多年的分布式系统经验告诉我们：可靠性的回报是非线性的。低于某个阈值，系统完全无法使用。高于该阈值，游戏规则随之改变。这里存在一个相变 —— 你需要站在正确的一边。

- **闭环。** 智能体的处理和编排应当是直观且自我修复的 —— 自动收敛到期望状态。生物学中的稳态，基础设施中的 Kubernetes。声明式意图，自动协调。单个智能体是可消耗的；而有机体长存。

## 工程原则 {#engineering-principles}

这些原则服务于云原生细胞化的论断：

- **文档就是新的源代码。** 在 AI 原生的工作流中，规范和文档是持久的产物 —— 代码是意图的下游。我们首先编写文档并保持其权威性，这样人类和智能体都能基于相同的真实来源进行工作。

- **证据胜于承诺。** 每个头条声明都附带一个针对用户安装的精确构建版本的公开、可复现的基准测试：固定版本、可审计的运行记录、[实时结果](https://antigma.ai/eval)。如果我们无法测量，我们绝不声称。

- **紧凑且微小的核心。** 每一行代码都是一种负担。小核心意味着可审计、编译速度快、易于推理 —— 并且轻量到足以在大规模下进行复制。

- **最小化认知负担。** 更少需要学习的概念，更少需要调节的旋钮。如果一个功能需要一整段话来解释，它可能太复杂了。

- **最小化依赖项。** 更少的依赖意味着更少的供应链风险、更快的构建速度，以及更少因上游更改而导致的损坏。我们宁愿采用供应商化（vendor）或重写，而不是添加另一个 crate。

- **避免供应商锁定 —— 包括我们自己的。** 您可以在不创建账户或不登录我们的情况下使用 Ante。自带您的 API 密钥、自由切换提供商，或者使用本地模型完全离线运行。

- **有原则的智能体组织。** 智能体应当是结构化的，而不是自由形态的。Ante 强制执行清晰的轮次生命周期和权限模型，以使智能体表现得可预测且透明。

- **闭环训练与推理。** 评估不是事后诸葛亮 —— 这是我们判断智能体框架是否有效运作的方式。我们不断针对现实世界的任务进行基准测试，并将结果反馈到开发中。

- **精选与主见。** 我们培养对炒作和噪音的抵抗力，并在达成共识的行业标准上加倍努力。
