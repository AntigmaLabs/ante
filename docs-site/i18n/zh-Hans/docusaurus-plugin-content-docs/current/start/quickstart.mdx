## 前置准备 {#prerequisites}

准备一个已有的模型服务账户或 API 密钥。如需在自己的机器上运行模型，请参阅[离线模式](/local/offline)。

## 安装 {#installation}

Ante 作为单一独立的二进制文件分发，没有任何外部运行时依赖 —— 下载即可直接运行。

```sh
curl -fsSL https://ante.run/install.sh | bash
```

默认情况下会安装至 `~/.ante/bin`，并配置 Shell 的 `PATH`。打开新终端后可运行 `ante`，或在当前终端中立即使用 `~/.ante/bin/ante`。运行 `ante --version` 可检查安装；本指南对应 **v0.3.4**。

若想安装到其他目录，可设置 `ANTE_INSTALL_DIR` 环境变量：

```sh
curl -fsSL https://ante.run/install.sh | ANTE_INSTALL_DIR=/usr/local/bin bash
```

请以普通用户身份运行默认安装脚本，不要使用 `sudo`。若使用 sudo 安装到用户主目录会导致 `~/.ante` 归属于 root 用户，从而阻止 Ante 正常保存设置和输入历史，因此安装脚本会拒绝该组合。

macOS 平台的发布二进制文件已经过 Apple 开发者证书签名与公证（Notarized），Gatekeeper 安全检查会自动放行。

## 在项目中完成第一个任务 {#start-with-your-existing-account-or-key}

<span id="interactive-session" />

在项目根目录中启动 Ante：

```bash
cd your-project
ante
```

<span id="use-a-different-provider" />

如果已在 Ante 中登录或已在当前终端导出 API 密钥，可以直接提问。首次连接时，输入 `/providers`，选择提供商，按 `m` 登录或粘贴密钥。详见[连接提供商](/usage/providers)。

先让 Ante 帮您找到运行代码的入口：

> 这个项目从哪里开始执行？请指出入口文件，以及覆盖这条执行路径的测试。

按 `Enter` 后，您可以看到 Ante 读取了哪些文件。然后在同一会话中追问：“怎样只运行这个测试？” 要指定文件，可输入 `@` 并从列表中选择。

### 从命令行登录 Antix {#log-in-with-antix}

在项目目录运行 `ante auth login antix`，在浏览器中完成登录，然后运行 `ante --provider antix` 即可开始上述任务。

## 快速示例 {#quick-examples}

### 单次执行（无头模式） {#headless-one-shot}

```bash
# 运行单个任务并退出
ante -p "add error handling to src/main.rs"
```

### 从标准输入通过管道传递内容 {#pipe-input-from-stdin}

```bash
# 传递文件内容进行分析
cat src/lib.rs | ante -p "review this code for bugs"
```

### 跳过工具审批 {#skip-tool-approvals}

```bash
# YOLO 模式 — 自动批准所有工具调用
ante --yolo -p "fix all clippy warnings"
```

### 作为服务端运行 {#run-as-a-server}

```bash
# 启动长寿命守护进程以进行编程集成
ante serve
```

### 更新到最新版本 {#update-to-the-latest-version}

```bash
# 检查新版本并安装
ante update

# 尝试开发通道单次更新
ante update nightly

# 回滚或锁定到指定发布版本
ante update --version v0.3.4
```
