## 前置要求

- 至少一个 LLM 提供商（如 Anthropic、OpenAI 等）的 API 密钥或订阅 —— 或使用无需 API 密钥的[离线模式](/experimental/offline)。

## 安装

Ante 作为单一且独立的二进制文件分发，无任何外部依赖 —— 下载即可运行。

```sh
curl -fsSL https://ante.run/install.sh | bash
```

默认情况下，程序会安装在 `~/.ante/bin`。若需自定义安装路径，请设置 `ANTE_INSTALL_DIR` 变量：

```sh
curl -fsSL https://ante.run/install.sh | ANTE_INSTALL_DIR=/usr/local/bin bash
```

## 快速示例

### 交互式会话

```bash
# 启动 TUI —— 与智能体对话、批准工具调用、查看代码差异
ante
```

### 无头模式 (单次运行)

```bash
# 执行单次任务后退出
ante -p "add error handling to src/main.rs"
```

### 通过标准输入 (stdin) 传递内容

```bash
# 通过管道传输文件内容进行分析
cat src/lib.rs | ante -p "review this code for bugs"
```

### 切换模型提供商

```bash
# 临时指定模型和提供商
ante --provider openai --model gpt-5.5 -p "refactor this function"
```

### 跳过工具审批

```bash
# YOLO 模式 —— 自动批准所有工具调用
ante --yolo -p "fix all clippy warnings"
```

### 作为服务端运行

```bash
# 启动长期运行的守护进程以供程序化集成
ante serve
```

### 版本更新

```bash
# 检查新版本并自动安装
ante update

# 更新至每日构建版本 (Nightly)
ante update nightly

# 回滚或锁定到指定版本
ante update --version v0.preview.33
```
