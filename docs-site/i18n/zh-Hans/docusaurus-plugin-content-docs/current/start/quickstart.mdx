## 前置准备

- 至少一家大语言模型提供商的 API 密钥或订阅（Anthropic、OpenAI、Gemini 等）—— 或者使用[离线模式](/local/offline)无需任何 API 密钥

## 安装

Ante 作为单一独立的二进制文件分发，没有任何外部运行时依赖 —— 下载即可直接运行。

```sh
curl -fsSL https://ante.run/install.sh | bash
```

默认情况下会安装至 `~/.ante/bin`。若想安装到其他目录，可设置环境变量 `ANTE_INSTALL_DIR`：

```sh
curl -fsSL https://ante.run/install.sh | ANTE_INSTALL_DIR=/usr/local/bin bash
```

请以普通用户身份运行默认安装脚本，不要使用 `sudo`。若使用 sudo 安装到用户目录会导致 `~/.ante` 归属于 root 用户，从而阻止 Ante 正常保存配置与历史记录，因此安装脚本会拒绝该组合。

macOS 平台的发布二进制文件已经过 Apple 开发者证书签名与公证（Notarized），Gatekeeper 安全检查会自动放行。

## 快速示例

### 交互式终端会话（TUI）

```bash
# 启动 TUI 交互界面 — 与智能体对话、审查并批准工具调用、查看代码 Diff
ante
```

### 单次执行（无头模式）

```bash
# 执行单个任务后自动退出
ante -p "为 src/main.rs 添加错误处理逻辑"
```

### 通过管道从标准输入传递内容

```bash
# 传递文件内容进行分析
cat src/lib.rs | ante -p "审查这段代码中的潜在 Bug"
```

### 切换模型提供商

```bash
# 指定提供商与模型
ante --provider openai --model gpt-5.6-sol -p "重构这个函数"
```

### 自动确认工具调用（免审批模式）

```bash
# YOLO 模式 — 自动批准所有工具调用
ante --yolo -p "修复所有的 clippy 警告"
```

### 作为服务端运行

```bash
# 启动长寿命守护进程，供外部程序以编程方式调用
ante serve
```

### 更新到最新版本

```bash
# 检查新版本并安装
ante update

# 尝试开发通道（nightly）
ante update nightly

# 回滚或锁定到指定发布版本
ante update --version v0.preview.86
```
