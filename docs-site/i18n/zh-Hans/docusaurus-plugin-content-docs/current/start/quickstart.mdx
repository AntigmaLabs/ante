## 前置准备 {#prerequisites}

- 一个 **Antix** 账户、**Anthropic (Claude)** 订阅、**OpenAI (ChatGPT/Codex)** 订阅，或提供商 API 密钥。
- 也可以使用[离线模式](/local/offline)，无需账户或 API 密钥。

## 安装 {#installation}

Ante 作为单一独立的二进制文件分发，没有任何外部运行时依赖 —— 下载即可直接运行。

```sh
curl -fsSL https://ante.run/install.sh | bash
```

默认情况下会安装至 `~/.ante/bin`。若想安装到其他目录，可设置 `ANTE_INSTALL_DIR` 环境变量：

```sh
curl -fsSL https://ante.run/install.sh | ANTE_INSTALL_DIR=/usr/local/bin bash
```

请以普通用户身份运行默认安装脚本，不要使用 `sudo`。若使用 sudo 安装到用户主目录会导致 `~/.ante` 归属于 root 用户，从而阻止 Ante 正常保存设置和输入历史，因此安装脚本会拒绝该组合。

macOS 平台的发布二进制文件已经过 Apple 开发者证书签名与公证（Notarized），Gatekeeper 安全检查会自动放行。

## 使用已有账户或密钥开始 {#start-with-your-existing-account-or-key}

已经有上述账户或提供商 API 密钥？进入项目目录，直接启动 Ante：

```bash
cd your-project
ante
```

如果已在当前 Shell 中导出 API 密钥，或之前已通过 Ante 登录，就可以直接发送提示词。Ante 会自动检测可用凭据；使用其他提供商无需登录 Antix。

Ante 会检测 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY` 和 `GEMINI_API_KEY` 等密钥。所有受支持的提供商与环境变量请参阅[提供商目录](/reference/catalog-reference#built-in-providers)。

首次在 Ante 中使用账户？输入 `/connect`，选择 **Antix**、**Anthropic Subscription** 或 **OpenAI Subscription**，然后在浏览器中完成登录。也可以通过 `/welcome` 粘贴 API 密钥，或通过 `/providers` 在已连接的提供商之间切换。

## 使用 Antix 登录 {#log-in-with-antix}

若要通过命令行连接 Antix 账户，可以在启动会话前登录：

```bash
ante auth login antix
```

在浏览器中完成登录，然后回到终端。Ante 会保存凭据供后续会话使用。

进入项目目录并开始对话：

```bash
cd your-project
ante --provider antix
```

可以先问：`解释这个项目的目录结构，并指出主要入口。`

也可以在 TUI 中登录：运行 `ante`，输入 `/connect` 并选择 **Antix**。其他提供商的 OAuth 登录及 API 密钥配置请参阅[连接提供商](/usage/providers)。

## 快速示例 {#quick-examples}

### 交互式会话 {#interactive-session}

```bash
# 启动 TUI — 与智能体对话、批准工具调用、查看 diff
ante
```

### 单次执行（无头模式） {#headless-one-shot}

```bash
# 运行单个任务并退出
ante -p "add error handling to src/main.rs"
```

### 从标准输入通过管道传递内容 {#pipe-input-from-stdin}

```bash
# 传递文件内容进行分析
cat src/lib.rs | ante -p "review this code for bugs"
```

### 切换模型提供商 {#use-a-different-provider}

```bash
# 覆盖模型和提供商
ante --provider openai --model gpt-6-sol -p "refactor this function"
```

### 跳过工具审批 {#skip-tool-approvals}

```bash
# YOLO 模式 — 自动批准所有工具调用
ante --yolo -p "fix all clippy warnings"
```

### 作为服务端运行 {#run-as-a-server}

```bash
# 启动长寿命守护进程以进行编程集成
ante serve
```

### 更新到最新版本 {#update-to-the-latest-version}

```bash
# 检查新版本并安装
ante update

# 尝试开发通道单次更新
ante update nightly

# 回滚或锁定到指定发布版本
ante update --version v0.2.5
```
